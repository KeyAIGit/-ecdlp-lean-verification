# UORC-056 C55: cycle label and open-translation boundary

Date: 2026-08-19

Status: exact scalar cycle labels, exact cycle-orientation norm, arbitrary-decoder collision for cycle-invariant states, scoped rational degree boundary, exact secp256k1 cycle certificate, and finite public-state screens. No public parity decoder, parity oracle, or sub-square-root ECDLP algorithm is claimed.

## 1. Input

C54 proves that the surviving charged tangent pair has one charge generator over the neutral field:

```text
B(P)=(x(P)/y(P))/(x(G)/y(G)),
A(P)=N(P)/B(P).
```

It also proves exact public addition and doubling laws. For secp256k1, the action generated by doubling, GLV, and negation has 32 cycles on the pair quotient.

C55 asks whether a cycle label or a within-cycle phase can return

```text
(-1)^k, Q=[k]G.
```

## 2. Exact cycle labels

Let

```text
M=ord_n(2), H=<2> subset (Z/nZ)^*.
```

Define

```text
L(k)=k^M mod n.
```

Then

```text
L(2k)=L(k),
ker L=H.
```

Thus `L` is an exact label of the multiplicative doubling cycle containing `k`.

When `M` is odd,

```text
L(-k)=-L(k).
```

The negation-invariant pair-cycle label is

```text
L_pair(k)=k^(2M) mod n.
```

For secp256k1:

```text
M=(n-1)/64,
M is odd,
L(k) in mu_64,
L_pair(k) in mu_32.
```

So the scalar cycle decomposition has exactly 64 oriented cycles and 32 pair cycles.

This is a compact six-bit scalar label, but no public evaluator of `L(k)` from `Q=[k]G` is found. Computing `k^M` after receiving `k` is easy; obtaining the same label from the elliptic-curve point is the hidden scalar-character problem.

## 3. A cycle label cannot determine point parity

Write the canonical residues in one doubling cycle as

```text
r_(j+1)=2r_j-n d_j,
d_j in {0,1}.
```

Since `n` is odd,

```text
r_(j+1) mod 2 = d_j.
```

Every nonzero odd-length doubling cycle contains both even and odd canonical residues.

Indeed, if every `r_j` were even, then every carry would be zero and `r_(j+1)=2r_j` as an integer at every step, which cannot close. If every `r_j` were odd, every carry would be one; then `n-r_(j+1)=2(n-r_j)`, which also cannot close.

Therefore one exact cycle label is shared by points with opposite parity. No function whatsoever of the cycle label alone can decode point parity. This includes arbitrary lookup tables and unbounded nonlinear post-processing. It is an information collision, not a low-degree screen.

## 4. Exact cycle-orientation norm

Define

```text
Eta(k)=product_(j=0)^(M-1) (-1)^[2^j k]_n.
```

This sign is invariant under doubling and, for odd `M`, changes sign under negation.

Summing the recurrence around the cycle gives

```text
sum_j r_j = n sum_j d_j.
```

Hence

```text
Eta(k)=(-1)^(sum_j r_j)=(-1)^(sum_j d_j).
```

So `Eta` is the parity of the number of upper-half carries in the full binary orbit. It supplies one orientation bit for a full cycle.

But `Eta` is constant on the cycle, while point parity is mixed on that cycle. Therefore `Eta` also cannot decode the parity of the current point.

## 5. The within-cycle problem

After choosing a representative `r` of one cycle, every scalar in that cycle has the form

```text
k=r 2^j mod n,
0 <= j < M.
```

The missing within-cycle value is the exponent `j`. Recovering `j` from `Q=[r 2^j]G` is a discrete logarithm in the odd-order subgroup `<2>` of size `M`.

For secp256k1 the generic baby-step giant-step cost is

```text
42535295865117307932921825928971026432,
```

which has 126 bits. This is the ordinary square-root scale reduced only by a constant factor of eight. Knowing the exact 64-state cycle label does not change the exponent of generic complexity.

The parity word along the cycle is the binary long-division carry word of `k/n`; it is not a character of the odd cyclic phase group.

## 6. Rational cycle-label boundary

Let `f` be a nonconstant rational function on the elliptic curve with pole degree `d`, and suppose `f([2]P)=f(P)` on all `n-1` nonzero subgroup points.

The rational function `f o [2] - f` has pole degree at most `5d`, since `[2]` has degree four. If `5d<n-1`, it has more zeros than poles and must vanish identically. But then pole degrees give `4d=d`, forcing `d=0`, contrary to nonconstancy.

Therefore any nonconstant rational cycle-invariant label satisfies

```text
d >= ceil((n-1)/5).
```

For secp256k1 this lower bound is

```text
23158417847463239084714197001737581570567512855814980876521032628303632298868,
```

a 254-bit pole degree.

This is a rational-function boundary, not an unrestricted arithmetic-circuit lower bound.

## 7. Public-state screens

The exact replay constructs the C54 public states `A,B,N,T,R,S` on ten prime-order `j=0` curves whose doubling order is odd. It tests cycle products, cycle sums, exact scalar labels, pair labels, canonical representatives, and anchor-normalized within-cycle phase states.

The declared decoders are quadratic characters with public structural affine shifts and canonical LSB, half, quartile, and octant bits.

No feature name survives uniformly across inherited and new held-out curves for either cycle orientation `Eta` or point parity inside a cycle. Some single small curves admit fitted formulas. They fail on held-out curves and are recorded as finite overfit.

## 10. Successor C56

The next package is

```text

```

It must attack one of two mechanisms:

1. a sublinear evaluator of a full doubling-orbit norm without materializing `M` orbit values;
2. a public charged relation crossing the 32 secp pair cycles and fixing the within-cycle phase.

A candidate is rejected if it only computes `L(k)`, only supplies `Eta(k)`, requires the exponent `j`, stores one value per orbit vertex, or remains at square-root total cost.
