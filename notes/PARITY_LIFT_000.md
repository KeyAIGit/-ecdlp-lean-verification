# PARITY-LIFT-000: generator-relative scalar parity through theta phase

Date: 2026-08-11

Status: **isolated, non-executable research draft**. No real key, wallet, or
production-sized discrete-log instance is targeted. This note does not change
Research Engine state, authorize an experiment, select a route, or claim an
ECDLP improvement.

## 1. Exact object

Let

```text
C = <G>
```

be a cyclic group of odd order `n`. For `Q in C`, let `rep_G(Q)` be the unique
integer `k` with

```text
0 <= k < n,    Q = [k]G.
```

Define the generator-relative scalar parity

```text
par_G(Q) = rep_G(Q) mod 2.
```

For secp256k1, `n` is the standard 256-bit prime subgroup order and the whole
rational point group is generated by `G`, as already recorded by the repository
point-group equivalence.

The desired object is not merely a theta coordinate map. It is a pair

```text
Lift(G,Q)    and    Decode(Lift(G,Q))
```

such that:

1. `Lift` is deterministic and computable from public `(curve,G,Q)` data;
2. it is sign-sensitive: it does not identify `Q` and `-Q`;
3. any projective/gauge ambiguity is normalized without knowledge of `k`;
4. `Decode(Lift(G,[k]G)) = k mod 2` for every canonical `k`;
5. the combined online, memory, precision, and preprocessing cost is below the
   correct generic baseline.

### Central correction

A canonical sign-sensitive coordinate lift exists in a weak sense: choose a
full projective embedding and normalize the first nonzero coordinate on each
chart. This is piecewise rational and efficiently recovers an ordinary
coordinate representative of `Q`.

That observation is **not** progress on ECDLP. An invertible coordinate change
cannot create information or lower complexity by itself. The real unknown is
an efficiently computable **parity decoder** on the lift. Any future proposal
must bind the lift and decoder as one mechanism and account for their total
cost.

## 2. Four foundation results

### 2.1 `scalarParity_neg`

For `Q=[k]G` with `0<k<n`,

```text
-Q = [n-k]G.
```

Because `n` is odd,

```text
(n-k) mod 2 = 1 - (k mod 2).
```

Therefore

```text
boxed: par_G(-Q) = 1 - par_G(Q)    for Q != O.
```

Scalar parity is anti-invariant under point negation.

### 2.2 `scalarParity_not_factor_through_Kummer`

Let `pi` be any representation satisfying

```text
pi(Q) = pi(-Q).
```

If a decoder `d` existed with `par_G = d o pi`, then for every nonzero `Q`,

```text
par_G(Q) = d(pi(Q)) = d(pi(-Q)) = par_G(-Q),
```

contradicting `scalarParity_neg`.

Therefore generator-relative parity cannot factor through:

- the genus-one Kummer quotient `E/{+1,-1}`;
- an x-only representation;
- `y^2`;
- even theta coordinates;
- any norm or invariant that erases the `Q` versus `-Q` distinction.

This cleanly separates the parity line from the current C6/GLV orbit-norm line,
which intentionally eliminates sign and phase for polynomial solving.

### 2.3 `no_global_alternating_translation_observable`

There is no nonzero global sign observable `F` satisfying

```text
F(Q+G) = -F(Q)
```

for every `Q in C`. Iterating the equation `n` times gives

```text
F(Q+nG) = (-1)^n F(Q) = -F(Q),
```

while `nG=O` requires `F(Q+nG)=F(Q)`.

The actual parity sign

```text
s_G([k]G) = (-1)^k
```

therefore cannot be a character of the odd-order group. Its translation rule
has one unavoidable cut defect: it flips at every successor except the wrap
from `-G=[n-1]G` to `O`, where both signs equal `+1`.

The target is consequently not a smooth order-two harmonic of translation by
`G`; it is a generator-relative cut function on the cyclic orbit.

### 2.4 `parityOracle_recovers_dlog`

Assume an exact oracle returns

```text
b_i = par_G(Q_i)
```

for arbitrary public points `Q_i`. Set `Q_0=Q` and recursively compute

```text
Q_(i+1) = [2^(-1) mod n] (Q_i - [b_i]G).
```

If `Q_i=[k_i]G` with canonical `0<=k_i<n`, then `k_i-b_i` is even and

```text
k_(i+1) = (k_i-b_i)/2.
```

Thus

```text
k = b_0 + 2 b_1 + 2^2 b_2 + ...,
```

and at most `ceil(log_2 n)` oracle calls recover the full discrete logarithm.
For a 256-bit prime-order group the upper bound is 256 calls plus ordinary group
arithmetic.

This is why exact scalar parity is not a small leak: it is an equivalent search
target for full ECDLP up to a logarithmic factor.

The toy-only validator under `experiments/parity_lift_000/` exhaustively checks
all four statements on the frozen odd cyclic groups of orders at most 127.

## 3. Fixed-level linear theta barrier

Let `E` be an elliptic curve and `L` an ample line bundle of degree `d`. The
Mumford theta group is a central extension over

```text
K(L) = ker(phi_L),
phi_L(a) = t_a^* L tensor L^(-1).
```

Translation by `G` has a linear lift on the fixed theta space `H^0(E,L)` only
if

```text
G in K(L),    equivalently t_G^* L is isomorphic to L.
```

Under the principal identification `E ~= Pic^0(E)`, an elliptic line bundle of
degree `d` induces multiplication by `d` up to the conventional sign. Hence

```text
K(L) = E[d].
```

If `G` has prime order `n`, the condition `G in E[d]` forces

```text
n divides d.
```

Riemann-Roch on a genus-one curve gives

```text
h^0(E,L) = d    for d > 0.
```

Therefore any fixed theta representation in which translation by the full
order-`n` generator acts through one globally linear operator must satisfy

```text
boxed: dimension H^0(E,L) >= n.
```

For secp256k1 this lower bound is approximately `1.16 * 10^77` coordinates.
It closes the proposed small fixed-level theta matrix mechanism; it does not
close nonlinear, chart-dependent, character-valued, or p-adic observables.

### Independent Fourier form of the same barrier

For odd `n`, put `omega=exp(2*pi*i/n)` and

```text
s(k)=(-1)^k,    0<=k<n.
```

Its discrete Fourier coefficients are

```text
S(j) = sum_k (-1)^k omega^(-jk)
     = 2 / (1 + omega^(-j)).
```

Every one of the `n` coefficients is nonzero. The maximum, near
`j=(n-1)/2`, has magnitude asymptotic to

```text
2n/pi.
```

If `A^n=I` acts on an `m`-dimensional characteristic-zero vector space, every
matrix coefficient `ell(A^k v)` contains at most `m` translation frequencies,
because `A` is diagonalizable with n-th roots of unity as eigenvalues. Exact
parity has all `n` frequencies, so

```text
boxed: m >= n.
```

This is more general than theta functions: no small linear translation
representation can output the exact canonical parity sequence as a matrix
coefficient.

## 4. Canonical nonprojective normalization barrier

Theta coordinates normally define a projective point. A globally regular lift
to the punctured affine cone would algebraically trivialize the associated
positive-degree line bundle. Such a line bundle is not trivial, so a global
regular nonvanishing normalization does not exist.

Piecewise chart normalizations do exist. They necessarily introduce chart
switching, zeros, or poles and merely return another representation of `Q`.
They become relevant only after an explicit decoder and total cost theorem are
provided.

## 5. Direct algebraic sign-output barrier

Suppose a nonconstant rational function `r in F_p(E)` has no pole on the
rational group and directly outputs parity signs:

```text
r([k]G) = (-1)^k
```

for all `n` rational points. Then `r^2-1` vanishes at all `n` points. If `d` is
the degree of the pole divisor of `r`, the zero divisor of the nonzero function
`r^2-1` has degree at most `2d`. Hence

```text
2d >= n,
boxed: d >= ceil(n/2).
```

If `r^2-1` vanishes identically, then `r=+1` or `r=-1` in the function field and
cannot represent nonconstant parity.

Thus no bounded-degree rational expression in theta coordinates can directly
return `+1/-1` parity on the full prime-order group. For secp256k1 the lower
bound is approximately `5.79 * 10^76`.

This statement does **not** cover arithmetic postprocessing such as a quadratic
character `chi(f(Q))`, because `f` itself need not take only two values.

## 6. The surviving hypothesis

After the preceding closures, the live question is narrower:

```text
Does there exist a public, sign-sensitive theta or line-bundle representation
and a nonlinear arithmetic decoder, evaluable below square-root cost, whose
value is the canonical generator-relative parity?
```

The surviving decoder classes include:

1. a multiplicative/additive field character applied to an explicit rational or
   theta expression;
2. a p-adic or analytic theta observable with an exact precision and truncation
   theorem;
3. a nonlinear cocycle whose global accumulated phase can be evaluated without
   traversing the unknown `k`-step orbit;
4. a different representation not governed by one fixed small linear theta
   space.

Every candidate must still satisfy sign sensitivity, gauge independence,
exceptional-locus coverage, exact recovery, and a complete cost model.

## 7. Highest-value next theorem: `CHAR-PARITY-001`

The Fourier calculation suggests a stronger analytic obstruction. If

```text
(-1)^k = chi(f([k]G))
```

for a low-degree rational function `f` and a nontrivial finite-field character
`chi`, then pairing with the near-half-frequency group character produces a
mixed character sum of magnitude approximately `2n/pi`.

A Weil/Deligne bound of the form

```text
|sum_P chi(f(P)) psi(P)| <= C(f) sqrt(p)
```

would force the conductor, and typically the degree, of `f` to be on the order
of at least `n/sqrt(p)`. Since `n` is comparable to `p` for secp256k1, this is a
square-root-scale lower bound.

This is **not yet accepted as a theorem in this line**. The next task is to pin
an exact primary-source bound, prove the relevant group-character sheaf is
nonexceptional, account for zeros and poles, and derive a literal degree or
conductor inequality. If completed, it would close a broad class of
quadratic-character theta decoders at approximately the same exponent as the
generic barrier.

## 8. Current answer to the central question

The question splits into three answers:

1. **Does a canonical sign-sensitive coordinate lift exist?** Yes, in a weak
   piecewise-chart sense; this is routine and does not help by itself.
2. **Can exact parity be a phase of a small fixed-level linear theta lift or a
   bounded-degree direct algebraic sign function?** No, under the precise
   mechanism classes above.
3. **Does any efficient nonlinear theta/character/p-adic parity decoder exist?**
   Open. No concrete candidate currently clears the map, normalization,
   exceptional-locus, recovery, and cost gates.

The work therefore narrows the hypothesis space rather than producing an
algorithm.

## 10. Claim boundaries and relation to existing work

- The existing theta/Jacobi screen correctly closes x-only/Kummer compression,
  direct formal-log linearization, and several solver-presentation claims.
- The GLV/C6 orbit-norm line remains a separate relation-solving route. Its
  sign-erasing invariant cannot directly answer scalar parity.
- This line neither rejects nor promotes those routes.
- A noisy predictor with accuracy above 50% is not automatically an oracle; an
  adaptive noisy-recovery theorem would be a separate obligation.
- All real-target computation remains outside this draft.
