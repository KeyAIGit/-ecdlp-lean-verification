## One-line objective

```text
E, G, Q=[k]G,
```

compute one exact generator-relative bit with total cost below `sqrt(n)`.

## Working reduction chain

```text

    <-> GLV carry g_G(Q), using public C3(Q)=g_G(Q)R3(Q)

```

The final recovery reductions exist. The missing operation is the first public decoder from `Q` to `rho_G`, hard `R3`, or carry.

## Package 027

Kernel-only CM data are generator-blind. The same subgroup is generated by `G` and `-G`, but their generator-relative carry labels are complementary. Therefore an un-oriented kernel/isogeny cannot select the correct half-kernel factor.

## Package 028

The ratio of two standard multiplicative theta/sigma splittings is a character. On a prime-order subgroup a nontrivial character is faithful of full order `n`; there is no nontrivial binary homomorphic quotient.

Result:

```text
standard splitting = trivial or full order-n dual phase.
```

## Package 029

Let

```text
z=zeta_n^k,
eta_G(Q)=z+z^lambda+z^(lambda^2).
```

Then

```text
(1-z)(1-z^lambda)(1-z^(lambda^2))
    =conjugate(eta_G(Q))-eta_G(Q),

g_G(Q)=-sign(Im eta_G(Q)).
```

Thus carry is exactly the orientation of one C3 Gaussian period relative to its conjugate. The period degree is `(n-1)/3`, with `(n-1)/6` conjugate orientation pairs.

## Package 030

For secp256k1,

```text
d=ord_n(p)=(n-1)/6,
p^(d/2)=-1 mod n.
```

Half-Frobenius sends `eta_k` to `eta_-k=conjugate(eta_k)`. Any Frobenius-invariant descent gives the same output on the pair, while carry changes sign. Therefore trace, norm, symmetric orbit data, minimal-polynomial coefficients, and the squared discriminant cannot decode carry.

## Package 031

The anti-Frobenius elements form a one-dimensional line over the half-Frobenius fixed subfield. The canonical first generator-sensitive seed is

```text
tau_G=A_G(G),
A_G(Q)=eta_G(Q)-conjugate(eta_G(Q)).
```

Normalize:

```text
U_G(Q)=A_G(Q)/A_G(G).
```

Then

```text
U_G(G)=1,
U_G(phi Q)=U_G(Q),
U_G(-Q)=-U_G(Q),
g_G(Q)=g_G(G) sign(U_G(Q)).
```

This is the sharpest exact object currently known. It removes arbitrary anti-Frobenius scale but not the need to evaluate the dual phase. Its natural explicit state count remains `(n-1)/6`.
