# SECP-13441 nonlinear phase route: closure checkpoint

Date: 2026-08-12

Branch: `research/parity-lift-000`

Research PR: `#365`

## Question

Can the publicly evaluable order-13441 phase of the perfectly periodic point
function, together with bounded public C6-invariant coordinate features, define
a same-curve carry or hard-branch R3 predicate that scales across subgroup
orders?

The tested carry residuals were

```text
carry_half_y = GLV carry * halfSign(y)
carry_chi_y  = GLV carry * quadraticCharacter(y)
```

Both residuals are C6 invariant. Multiplication by the same public odd
orientation recovers the original carry sign.

## Decision

Close the following scoped route:

> Fixed bounded-capacity same-curve classifiers using the order-13441 phase,
> the frozen harmonic bank, and the tested C6-invariant coordinate statistics
> do not provide an admitted carry or hard-R3 predicate on the current toy
> families.

This is not a lower bound against all nonlinear circuits, all phase powers, or
all public predicates. In particular, it does not close the large remaining
prime factor of `p - 1`, arbitrary high-conductor circuits, or compact
CM/theta factorizations.

Do not spend another package on retuning these three models or expanding the
same 13441 lookup family without a new exact identity.

## Returned primary target

The sharpest constructive object remains the generator-oriented half-kernel
factor

```text
P_G(Y) = H_G(Y) H_G(-Y)
```

where

```text
H_G(y([k]G)) = 0 exactly on one GLV carry class.
```

The next package is

```text
HALF-KERNEL-COMPACT-CM-FACTOR-027
```

Its theorem target is:

> Let `alpha = a + b*phi` be the degree-n CM isogeny whose kernel is the public
> prime-order subgroup generated by `G`, with `Norm(alpha) = n` and
> `a + b*lambda = 0 mod n`. Determine whether the oriented quotient
>
> `R_G(Y) = H_G(Y) / H_G(-Y)`
>
> admits evaluation from `alpha`, its conjugate, Frobenius, and a bounded
> number of net/theta line functions using total time and storage
> `O(n^(1/2-epsilon))` for some fixed positive epsilon.

Required stages:

1. Construct and independently verify the exact Eisenstein norm representation
   and the kernel relation for every frozen subgroup and for secp256k1.
2. Write the divisor of the compact CM sigma or net function attached to
   `alpha` and identify every public normalization factor.
3. Test whether a cubic-theta or elliptic-unit factor selects the carry-positive
   C3 half, rather than merely reproducing the already public `g*R3` product.
4. Derive a black-box evaluation recurrence for the oriented quotient, or a
   scoped obstruction for the proposed representation.
5. Promote only an exact identity with explicit operation count and a literal
   carry-to-ECDLP recovery reduction.

No external point, key, wallet, or production-sized target is accepted.
