# UORC-056 H-RPCX compact specification gap V4

## Positive theorem

Exact canonical parity already has a constant-size public specification that never mentions the hidden scalar.

Let `f` be a function on the odd cyclic subgroup generated by `G`. Then parity is the unique function satisfying

- `f(O) + f(-G) = 2`;
- `f(Q) + f(Q-G) = 0` for every `Q != O`.

Equivalently,

`(I + T) f = 2 delta_O`,

where `T` is translation by `-G` and `delta_O` is one at the identity and zero elsewhere.

## Proof

Starting at `O`, the first equation fixes the sum across the unique wrap edge. Every other edge forces the sign to flip. Because the cycle length is odd, propagating these relations around the whole cycle closes consistently only with

`f([k]G) = (-1)^k`.

Uniqueness also follows from the V1 inverse identity. The operator `I+T` is invertible on an odd cycle and

`(I+T)^(-1) = (1/2)(I-T+T^2-...+T^(n-1))`.

## What this proves

A very short nonconstructive or implicit description of parity exists.

The description uses only:

- the public group law;
- the public generator `G`;
- equality with the identity;
- one local equation.

No table of parity values is needed to state the object.

## What this does not prove

It does not provide a `poly(log n)` random-access evaluator.

Direct propagation from `O` to `Q=[k]G` takes `k` local steps. Applying the explicit inverse materializes all `n` cyclic shifts. V1 proves that no low-dimensional linear translation-stable compression can make this inverse sparse.

Thus compact specification complexity and evaluation complexity are different quantities.

## Engine rule

A candidate is not an H-RPCX solution merely because it gives:

- a short recurrence;
- a sparse local constraint system;
- a unique variational characterization;
- a short equation whose solution is parity.

It must additionally provide a public random-access procedure that evaluates the unique solution at an encoded point `Q` in `poly(log n)` total cost.

## New central gap

After V4, the positive problem can be stated sharply:

> Find a public polylogarithmic random-access solver for the single entry of the inverse of `I+T`, where the queried basis position is supplied as the elliptic-curve point `Q`, not as the unknown integer index `k`.

Such a solver is exactly a parity oracle and therefore yields ECDLP by bit peeling.

The compact local equation is useful because it supplies a canonical target for nonlinear preconditioning, multiscale transport, theta lifting, CM decomposition, or modular composition. It is not itself the final algorithm.
