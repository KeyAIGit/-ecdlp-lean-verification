# UORC-056 H-RPCX autonomous linear-state barrier V6

## Status

Scoped paper theorem with an exact secp256k1 multiplicative-order certificate and deterministic finite replay.

This result is not yet formalized end to end in Lean. It does not rule out nonlinear, coordinate-dependent, query-dependent, or direct arithmetic-circuit evaluators.

## Model

Let the subgroup order `n` be an odd prime, let the base-field characteristic be the distinct prime `p`, and put

`K = ord_n(p)`.

Here `K` is the least positive integer for which

`p^K = 1 mod n`.

Consider a state sequence intended to follow the public generator steps

`O, G, [2]G, ..., [n-1]G`.

The state lies in `F_(p^d)^r`. One fixed update rule is applied at every step. The final decoder may be any deterministic function. It need not be linear, polynomial, rational, or cheap.

The only requirement is exactness:

`decode(state_k) = (-1)^k`

for every canonical index `k`.

## First lemma: the state orbit must have length n

Canonical parity on an odd cycle has no nontrivial rotational period.

Suppose two states were equal:

`state_i = state_j`

for `0 <= i < j < n`.

Because the update is deterministic and identical at every step, all future states would also agree after the same shift. The decoded parity word would then be invariant under the nonzero rotation `j-i`.

That is impossible. The odd-cycle parity word has one unique equal-sign wrap edge, so no nonzero rotation preserves it.

Therefore all `n` states are distinct and the state orbit has exact length `n`.

## Linear update theorem

Assume the update is linear:

`state_(k+1) = A state_k`.

Let `W` be the cyclic subspace generated by one orbit state. Since the orbit has length `n`, the restriction of `A` to `W` has exact order `n`.

Over `F_(p^d)`, every irreducible factor carrying a primitive `n`-th root has degree

`ord_n(p^d) = K / gcd(K,d)`.

Therefore

`r >= K / gcd(K,d)`.

Since `gcd(K,d) <= d`, this implies the base-field dimension bound

`d*r >= K`.

The decoder can be arbitrarily nonlinear. The bound comes from the state orbit and the fixed linear update, not from the readout.

## Affine update theorem

Assume the update is affine:

`state_(k+1) = A state_k + b`.

Add one homogeneous coordinate and represent the update linearly on

`F_(p^d)^(r+1)`.

The same cyclic-subspace argument gives

`r+1 >= K / gcd(K,d)`,

and hence

`d*(r+1) >= K`.

Thus adding a constant translation does not create a small autonomous exact parity state.

## Mobius update corollary

A fixed Mobius transformation acts on the projective line over `F_(p^d)`.

An exact parity state would require an orbit of length `n`. For `n != p`, an element of order divisible by `n` in `PGL_2(F_(p^d))` forces

`n | p^(2d)-1`.

Therefore

`K | 2d`

and

`d >= ceil(K/2)`.

## Exact secp256k1 value

For secp256k1, the replay proves

`K = ord_n(p) = (n-1)/6`.

The exact value is

`19298681539552699237261830834781317975472927379845817397100860523586360249056`.

It has 254 bits.

Consequently:

- a fixed linear state over the base field needs at least `K` field coordinates;
- a fixed affine state over the base field needs at least `K-1` coordinates;
- a one-coordinate Mobius state needs extension degree at least `ceil(K/2)`.

These sizes are exponential in the 256-bit input length. They are not polynomial in `log n`.

## What V6 closes

V6 closes every architecture with all of the following properties:

1. the state advances under `Q -> Q+G` by one fixed linear or affine rule;
2. the state uses only polynomially many base-field dimensions;
3. the decoder is exact on the complete secp256k1 subgroup.

The decoder may be arbitrarily nonlinear. That does not avoid the orbit-dimension obstruction.

## What V6 does not close

V6 does not exclude:

- nonlinear state updates;
- updates whose coefficients depend on the current point coordinates;
- query-dependent random-access constructions that do not walk by `+G`;
- high-degree functions computed by small DAG circuits;
- modular composition or jump-ahead identities;
- coherent CM, Miller, theta, elliptic-unit, or p-adic transport;
- a direct secp256k1-specific evaluator outside this autonomous-state model.

## Anomalous controls

Toy instances with `p=n` are explicitly excluded from this theorem. In characteristic `n`, unipotent or translation dynamics can have `n`-cycles for p-primary reasons, and `ord_n(p)` is not defined.

This exclusion is necessary and is recorded rather than silently ignored.

## Research consequence

The next positive candidate must not be another fixed linear, affine, or Mobius phase transport with a cleverer decoder.

It must introduce at least one genuinely new feature:

- nonlinear coordinate-dependent evolution;
- a random-access jump that does not simulate every generator step;
- a high-degree low-DAG-size direct evaluator;
- or a nonlocal oriented transport tied to the public generator and query.
