# UORC-056 C55 contract: cycle label or open translation

Date: 2026-08-19

Status: successor research contract. No parity evaluator is claimed.

## 1. Input from C54

C54 proves that the charged moduli-tangent pair has rank one over the neutral field:

```text
B(P)=(x(P)/y(P))/(x(G)/y(G)),
A(P)=N(P)/B(P).
```

It derives exact addition and doubling laws and finds no parity decoder in the declared transfer grammars.

For secp256k1 the multiplier action generated by `2`, `lambda`, and `-1` has 32 cycles on the pair quotient. One anchor leaves 31 independent cycle signs when only neutral or squared transfer data are supplied.

## 2. Exact C55 question

Construct either:

```text
a public cycle label together with a within-cycle oriented phase,
```

or:

```text
a compressed unsquared open transport from G to Q.
```

The output must determine

```text
(-1)^k, Q=[k]G,
```

without a scalar-labelled path.

## 3. Mandatory targets

C55 must:

1. distinguish cycle identification from within-cycle position;
2. derive the exact action of doubling, halving, GLV, and negation on the proposed state;
3. test whether the long-division carry word can be evaluated without recovering the orbit exponent;
4. reject advice containing one hidden phase per query or one table value per orbit vertex;
5. account for preprocessing, advice, memory, representation, and online cost;
6. validate on frozen, inherited held-out, and new held-out curves;
7. include independent replay and Lean checks for the algebraic core.

## 4. Immediate rejection rules

Reject any candidate that:

```text
returns only one of the 32 cycle identifiers,
requires solving Q=[2^j r]G for j,
uses an order-n table,
uses a signed tangent or connection value equivalent to k,
only rewrites the public x/y endpoint charge,
or reaches Omega(sqrt(n)) total cost.
```

## 5. Success outcomes

C55 must end with one of:

1. a public sub-square-root parity evaluator;
2. a scoped no-go theorem for the declared cycle/open-transport grammar;
3. a new compact oriented phase state with a separately stated unresolved evaluator.
