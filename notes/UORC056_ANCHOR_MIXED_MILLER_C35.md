# UORC-056 C35: anchor-mixed Miller boundary

Status: active scoped negative/transition package. No parity evaluator is claimed.

## Target

C34 proved the exact three-carry identity

\[
\sigma_G(Q)=C_G(Q,A)C_G(A,B)C_G(-T,-B),
\]

with `A=[2]Q`, `T=[-1/2]Q`, `B=T-A`.

C35 asks whether this constant-width semantic aggregate can be realized by a public field-valued construction that genuinely consumes the generator anchor `Y_G(x(G))=-y(G)`.

## 1. Pairing degeneracy

Any genuine bilinear alternating n-pairing is useless on this geometry. Since `Q=[k]G`, every point used by the C34 three-carry configuration lies in the same cyclic subgroup generated by `G`. Therefore

\[
e_n([a]G,[b]Q)=e_n(G,G)^{abk}=1.
\]

Hence Weil-pairing output, and any construction depending only on such finalized pairing values, cannot distinguish parity. This does not close unfinalized Miller values.

## 2. Anchor-normalized division-polynomial character grammar

We next tested a stronger generator-sensitive character grammar. Let the seven public C34 locations be

`Q, A=2Q, T=-Q/2, B=T-A, -T, -B, U=Q+A`.

For every index `2 <= m <= 29` and every symbolic location `u`, define the safe normalized atom

\[
X_{m,u}(Q)=\chi\!\left(\frac{\psi_m([u]Q)}{\psi_m([u]G)}\right).
\]

On the frozen curve `p=43, n=31, G=(2,12)`, all these denominator and numerator values are nonzero for the declared screen. The grammar permits an arbitrary product of any subset of the 196 atoms, equivalently an arbitrary F2-linear combination of their sign bits, plus one global phase.

Exact Gaussian elimination gives an inconsistent augmented system. Thus no product in this entire 196-atom grammar equals parity on the declared frozen curve. A single frozen counterexample is sufficient to reject an exact universal formula in this grammar.

This strictly contains using one or several ordinary division-polynomial quadratic characters at the three-carry points, normalized by the public generator.

## 3. Raw Miller values remain open

The important surviving class is not a finalized pairing and not a product of residue signs of division-polynomial values. It is an unfinalized, anchor-dependent Miller or elliptic-net value whose full field element is retained until the end.

The natural object is a regularized version of

\[
f_{m,G}(R),\qquad R=[u]Q,
\]

or a mixed product of a constant number of such cells over the three-carry geometry, with public `m` of size O(n) but addition-chain evaluation cost O(log n).

Direct affine Miller recurrences can show intermediate 0/0 when both source and evaluation lie in the same n-cycle even though the divisor-theoretic function may be regular at the final point. Therefore the next package must use one of:

1. projective/regularized Miller evaluation,
2. symbolic cancellation in the local ring,
3. elliptic-net cells with exceptional cases removed algebraically,
4. a resultant/determinant representation of the same unfinalized function.

## Decision

Closed in C35:

- finalized Weil/Tate pairing values on the single cyclic subgroup;
- arbitrary quadratic-character products of the 196 declared anchor-normalized division-polynomial atoms.

Still open:

- full field-valued unfinalized Miller/elliptic-net aggregates;
- anchor-mixed resultants or transfer matrices retaining more than one residue bit.
