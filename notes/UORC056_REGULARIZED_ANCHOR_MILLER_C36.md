# UORC-056 C36: regularized anchor Miller checkpoint

Status: active positive-structural / negative-decoder checkpoint. No parity evaluator is claimed.

## 1. Why regularization is necessary

For source `P=G` and evaluation point `Q=[k]G`, a short Miller addition chain can encounter intermediate factors with zero numerator or denominator because the evaluation point lies on the same cyclic orbit. The final divisor-theoretic function can nevertheless be regular and nonzero at `Q`. Treating intermediate affine `0/0` as failure therefore discards legitimate candidates.

C36 implements local-ring evaluation with local parameter

```text
t = x - x(Q)
```

at every nonzero odd-order point. Since `y(Q) != 0`, this is a valid local parameter. The series

```text
y(Q+t)=y0+c1 t+c2 t^2+c3 t^3+...
```

is obtained recursively from `y^2=x^3+7`. Every Miller line and vertical factor is represented by `(valuation, leading_coefficient)`. Products, quotients and squaring then propagate these pairs exactly through the addition chain. This removes spurious intermediate 0/0 without introducing hidden scalar information.

## 2. Exact divisor sanity check

For a Miller function `f_(m,G)` with divisor

```text
m[G]-[mG]-(m-1)[O],
```

the regularized evaluator reproduces the expected valuations on every frozen subgroup point:

```text
ord_Q f_(m,G)=m       if Q=G,
ord_Q f_(m,G)=-1      if Q=[m]G and Q!=G,
ord_Q f_(m,G)=0       otherwise,
```

with the obvious combined case when the supports coincide.

This validates the local evaluator independently of any parity hypothesis.

## 3. First large-index test

The most important candidate is `m=n`. Its divisor is

```text
n[G]-n[O],
```

while its value is generated by a public O(log n) Miller addition chain. Thus it has exactly the degree-versus-circuit shape that earlier degree lower bounds do not exclude.

On all five frozen curves, the quadratic character of the regularized leading coefficient of `f_(n,G)(Q)` is not parity. The same is true for the declared indices

```text
n-1, (n-1)/2, (n+1)/2, 2, 3, 5, 7, 8.
```

So one residue bit of one regularized Miller value is insufficient.

## 4. Full field values contain strictly more information

For each frozen base generator, no single declared Miller state `(valuation, leading_coefficient)` determines parity. However several pairs do determine parity on every one of the five finite toy screens when an arbitrary lookup decoder is allowed. One persistent example is the pair

```text
S(Q)=((ord,lead) of f_(n,G)(Q), (ord,lead) of f_(3,G)(Q)).
```

This is not a positive algorithm. On finite fields two field elements can encode enough information to identify many points, and an arbitrary lookup decoder may cost O(n). The observation only proves that raw Miller state retains information that quadratic-character projection destroys.

## 5. Cheap decoder screen

For the pair `(f_(n,G), f_(3,G))`, exhaustive affine-character decoding

```text
chi(a F_n + b F_3 + c)
```

was screened on each frozen curve, with projective normalization of `(a,b)` to avoid redundant scaling. No exact decoder exists on any of the five curves.

Likewise, the F2 span of the quadratic-character bits of the declared single Miller states is inconsistent with parity.

## 6. Interpretation

C36 therefore establishes a useful three-level separation:

```text
finalized pairing               -> provably trivial on <G>,
residue sign of raw Miller      -> insufficient,
full raw regularized field data -> informative, but cheap decoding unresolved.
```

The next mathematical question is no longer whether a high-degree short circuit exists: `f_(n,G)` already is one. The question is whether its full field value admits a generator-relative decoder of sub-root cost that does not amount to a table or discrete logarithm.

## 7. Successor

`MILLER-STATE-DECODER-C37` should attack the decoder directly. Priority order:

1. multiplicative relations between `F_n(Q)`, `F_n(Q+G)` and the public anchor;
2. norm/trace and low-degree rational decoders of `(F_n,F_3)` and `(F_n,F_(n-1))`;
3. GLV covariance of the full Miller state under `Q -> alpha Q`;
4. whether the sequence `F_n([k]G)` satisfies a short public recurrence whose branch is exactly parity;
5. decoder complexity lower bounds if all low-degree relations fail.
