\[

## 2. CM weight of division polynomials

On a curve

\[
y^2=x^3+7,
\]

the standard division-polynomial recurrence has a simple transformation rule:

\[
\psi_m(\beta x,y)=
\begin{cases}
\beta\,\psi_m(x,y),&3\mid m,\\
\psi_m(x,y),&3\nmid m.
\end{cases}
\]

This is called a **CM weight**. It only records how a function changes under the cubic GLV symmetry.

For the raw state, the numerator index is `p-1`, which is divisible by three, while the denominator index is `p-1+n`, which is not divisible by three because `n=1 mod 3`. The root exponent used to define `Phi_raw` is also `1 mod 3`.

Therefore

\[
\boxed{
\Phi_{\rm raw}(\alpha Q)=\beta\Phi_{\rm raw}(Q).
}
\]

Applying the symmetry twice gives

\[
\boxed{
\Phi_{\rm raw}(\alpha^2Q)=\beta^2\Phi_{\rm raw}(Q).
}
\]

\[
M_0=\Phi+\beta\Phi+\beta^2\Phi=0,

\[

\[
M_2=\Phi+\beta(\beta\Phi)+\beta^2(\beta^2\Phi)=0.

The product also gives nothing new:

\[

Thus sums, products, ratios, and Fourier resolvents built only from this triple remain functions of one original state.
