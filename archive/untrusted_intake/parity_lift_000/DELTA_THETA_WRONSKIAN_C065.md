# DELTA-THETA-WRONSKIAN-C065

Date: 2026-08-13

Status: **the canonical arithmetic Frobenius Wronskian of fixed-weight theta components factorizes into an ordinary multiplicative theta product, or vanishes when the weights coincide. It does not create an independent generator-oriented branch.**

No external point, private key, wallet, or production-sized discrete-log target is accepted.

## 1. Arithmetic Moore/Wronskian determinant

Let `Phi` be the lifted arithmetic Frobenius and let `f,g` be two section values. The natural characteristic-p arithmetic Wronskian is the Moore determinant

```text
W_Phi(f,g)=f*Phi(g)-g*Phi(f).                    (W1)
```

Equivalently, after writing

```text
Phi(a)=a^p+p*delta(a),
```

its first normalized p-adic layer is the corresponding delta-Wronskian. Formula `(W1)` is preferable because it is exact and respects the semilinear Frobenius action.

## 2. Fixed eigenweights force factorization

Suppose the two theta components have known Frobenius weights

```text
Phi(f)=alpha f,
Phi(g)=beta g.                                    (W2)
```

Then

```text
boxed:
W_Phi(f,g)=(beta-alpha) f g.                     (W3)
```

Consequently:

```text
alpha=beta  -> W_Phi(f,g)=0,
alpha!=beta -> W_Phi(f,g) is one public constant times f*g.
```

No additive branch or new projective orientation survives.

## 3. Application to the characteristic-root theta lift

The C053 components `Theta_0,Theta_1,Theta_2` have fixed cubic Frobenius weights. Every pairwise Frobenius Wronskian therefore satisfies `(W3)`.

After the same cubic/base-field descent used in C053, the resulting values lie in the multiplicative algebra generated by

```text
Theta_a^3,
Theta_a Theta_b Theta_c,
and public constants.
```

These are precisely the unshifted multiplicative features already screened in C053. The arithmetic differential notation does not produce a new object.

## 4. Common normalization does not help

If both sections are multiplied by one point-dependent scalar `r`, then

```text
W_Phi(rf,rg)=r*Phi(r)*W_Phi(f,g).                (W4)
```

Thus a common normalization contributes only its explicit norm-like factor. If that factor carries the desired bit, it was already present before forming the Wronskian.

For independently normalized rows, the residual is again the supplied row factors, as in package 051.

## 5. Projective ratio form

When `f` is nonzero, `(W1)` may be rewritten as

```text
W_Phi(f,g)=f*Phi(f) * (Phi(g/f)-g/f).             (W5)
```

Hence the only potentially new datum is the arithmetic Frobenius difference of the projective ratio `g/f`.

For the fixed-rank characteristic-root construction, all rational projective invariants are generated by the cross-ratios studied in C055. Applying Frobenius to them gives no independent theta orientation; it is a p-adic transform of the same public projective coordinate.
