# GLV-CARRY-SEPARATION-005

Date: 2026-08-11

Status: **isolated, non-executable structural-classification package**.
No external point, key, wallet, or production discrete-log instance is
accepted. This package changes no canonical Research Engine state and makes no
asymptotic-improvement claim.

## 1. Starting point

`NONLOCAL-ODD-ANCHOR-004` isolated the first genuine odd EDS-residue
aggregate on secp256k1-type Kummer-invariant instances:

```text
R3(Q)
  = rho_G(Q)
    rho_G(phi(Q))
    rho_G(phi^2(Q)).
```

Let the canonical scalar representatives of the three GLV-orbit points be

```text
k_0, k_1, k_2 in {1,...,n-1}.
```

They satisfy

```text
k_0+k_1+k_2 = gamma(Q)*n,
gamma(Q) in {1,2}.
```

For secp256k1, put

```text
g(Q)=(-1)^gamma(Q).
```

The public point-function orbit norm is

```text
C3(Q)=g(Q)R3(Q).
```

Thus one additional public section is sufficient only if its C3 orbit norm has
a normalization multiplier different from `g`.

The objective of this package is to classify all efficiently evaluable
algebraic sections already constructed in the parity branch.

## 2. Section family

For every retained Kummer-invariant toy subgroup, the screen evaluates:

1. the invariant first torsion jet

   ```text
   J1(Q)=chi(2*y(Q)*d psi_n/dx(Q));
   ```

2. the coordinate character `chi(x(Q))`;

3. the characters of Taylor coefficients two through four in

   ```text
   psi_n(x(Q)+T);
   ```

4. near-period sections

   ```text
   chi(psi_(n+a)(Q)),      1 <= |a| <= 4;
   ```

5. every distinct product of at most four C3 orbit norms from the retained
   family.

The anomalous case `p=n=547` is excluded from the torsion-jet layer because
`psi_n` is inseparable in characteristic `n`.

## 3. Exact multiplier classes

For any base section `A`, define its public C3 orbit norm

```text
N_A(Q)=product_(i=0)^2 A(phi^i(Q)).
```

The classifier compares `N_A`, up to one public global sign, against three
targets:

```text
R3(Q),
g(Q),
g(Q)R3(Q).
```

Across all eight retained Kummer-invariant cases, exactly the following
sections land in the dependent `gR3` class:

```text
J1,
psi_(n-1),
psi_(n+1).
```

More precisely:

```text
N_J1(Q)       = constant_G * g(Q)R3(Q),
N_(n+1)(Q)    =                 g(Q)R3(Q),
N_(n-1)(Q)    =              -  g(Q)R3(Q)
```

with the generator-dependent sign in the first line already predicted by the
exact first-jet law.

No retained single section equals `R3` or `g` up to a global sign.

This is the central result of the package:

> Every exact odd section currently available has the same GLV canonical-lift
> multiplier as the public point-function norm.

Therefore none gives a second independent equation.

## 4. Product closure

Products of public orbit norms could in principle cancel the carry multiplier.

The screen constructs all distinct products of weight at most four. Depending
on exceptional zeros, this gives between

```text
197 and 321
```

distinct product vectors per retained case.

Results on every retained case:

```text
exact products equal to R3:    0
exact products equal to g:     0
```

In particular, combining the known `gR3` sections only produces constants or
other even-gauge expressions; it does not isolate either hidden component.

## 6. Evidence for normalization rigidity

The exact coincidence of three independently defined sections is more
informative than three unrelated negative correlations:

```text
point-function section,
first order-n torsion jet,
nearest positive and negative period sections
```

all induce the same `gR3` orbit multiplier.

This suggests a scoped rigidity principle:

> Algebraic sections generated by the standard division-polynomial line
> bundle, its local jets, and bounded period translates inherit one quadratic
> refinement. Their odd C3 orbit norms all carry the same canonical-lift
> cocycle.

The present package does **not** prove this theorem. It establishes the exact
base cases and a bounded product closure. A proof would require identifying
the relevant theta-line bundle, its GLV linearization, and the induced
quadratic refinement independently of coordinates.

## 7. The carry is structured, but not yet computable from a point

The bit

```text
gamma(k)
  = (k + rep(lambda*k) + rep(lambda^2*k))/n
```

is not random as a scalar function. It is a triangular carry predicate for the
Eisenstein/GLV lattice and is invariant under multiplication by `lambda`,
while

```text
gamma(n-k)=3-gamma(k).
```

Its binary linear complexity varies across small toy orders and reaches the
random half-length scale on the largest retained case:

```text
order 3469:
carry linear complexity = 1734 of 3468 terms.
```

A public oracle for `gamma([t]Q)` under chosen scalar transformations would
look like a hidden-number oracle for a known triangular subset of
`Z/nZ`. Whether that oracle admits a classical sub-square-root recovery
algorithm has not yet been established.

This creates a second, algorithmic route:

1. prove that a GLV carry oracle recovers `k` efficiently; then a decoder for
   `R3` is immediately cryptanalytically meaningful through
   `C3=gR3`;
2. or prove a lower bound in an appropriate oracle model.

```text

single section decoding R3:                           none
```

The package therefore does not solve the central EDS-residue problem, but it

## 9. Successor questions

### A. `GLV-NORMALIZATION-RIGIDITY-006`

Prove or refute:

> Every efficiently evaluable algebraic section in the division-polynomial /
> bounded-isogeny / finite-jet tensor category has the same C3 carry multiplier
> as the perfectly periodic point function.

A proof would close a large algebraic class at once. A counterexample would
supply the required second equation.

### B. `GLV-CARRY-HIDDEN-NUMBER-006`

Study the oracle

```text
O_k(t)=gamma(rep(t*k)).
```

Determine whether chosen-multiplier queries recover `k` in polynomial or
sub-square-root time. The set `gamma=1` is a known triangular fundamental
domain for the order-three GLV action, so this is more structured than a random
predicate.

The next work should run these two questions in parallel, with the rigidity
theorem first because it decides whether more algebraic-section enumeration is
worthwhile.
