# DIRECT-GLV-CIRCUIT-011

Status: **isolated bounded research package; no production target**.

## Question

`DIRECT-GLV-CARRY-DESCENT-010` reduced every rational candidate with the
required GLV and negation symmetries to

```text
F(Q) = y(Q) * R(x(Q)^3).
```

Let

```text
z(Q) = x(Q)^3,
h(Q) = g(Q) * chi(y(Q)).
```

The direct selector condition is therefore

```text
chi(R(z(Q))) = h(Q)
```

on the `(n-1)/6` quotient points obtained from the order-six action generated
by GLV and negation.

Package 010 ruled out all split products with at most four ordinary linear
factors and all rational square classes of total degree at most two on every
frozen subgroup of order at least `271`. Package 011 asks whether algebraic
degree can be made large while straight-line complexity stays small.

## Cost model

For a positive exponent `e`, define

```text
binary_mul_cost(e)
  = bit_length(e)-1 + popcount(e)-1.
```

This is the multiplication count of ordinary left-to-right binary
exponentiation. The frozen limit is

```text
binary_mul_cost(e) <= 7.
```

Under this declared method, every considered unreduced exponent is at most
`128`. The cost is not claimed to be the minimum addition-chain complexity.

## Exact finite grammars

### A. Up to two power-affine factors

The screen exhausts

```text
R(z) = u * product_{j=1}^d (z^(e_j) + c_j),
0 <= d <= 2,
chi(u) in {+1,-1},
binary_mul_cost(e_j) <= 7,
c_j in F_p.
```

Every primitive polynomial is rejected when it vanishes on a sampled quotient
point. Each surviving primitive is converted to its complete binary character
vector. Exact one-factor and two-factor hits are then found by full XOR lookup.
No probabilistic hashing is used for acceptance.

On the largest frozen case

```text
p = 3931,
n = 4021,
quotient points = 670,
```

the grammar contains

```text
186273 valid primitive polynomials,
186219 distinct primitive character patterns,
34697816804 nominal classes with at most two factors.
```

There is no exact decoder.

### B. Shifted powers

The screen exhausts

```text
R(z) = u * ((z+a)^e + b),
a,b in F_p,
chi(u) in {+1,-1},
binary_mul_cost(e) <= 7.
```

For every pair `(e,a)`, the complete set of admissible `b` values is
intersected with bit masks encoding the required quadratic-character signs.
Any surviving candidate is replayed point by point.

### C. Sparse trinomials

The screen exhausts

```text
R(z) = u * (z^e + a*z + b),
a,b in F_p,
chi(u) in {+1,-1},
binary_mul_cost(e) <= 7.
```

The same exact bit-mask intersection and full replay are used.

### D. All monic cubic square classes on stratified fields

For every frozen field with

```text
p <= 1663,
```

the screen exhausts

```text
R(z) = u * (z^3 + A*z^2 + B*z + C),
A,B,C in F_p,
chi(u) in {+1,-1}.
```

This includes reducible and irreducible cubics. Larger fields are explicitly
marked `not_run_field_threshold`; no negative claim for the full cubic family
is made there.

## Frozen result

Exact fits occur only on the three tiny quotient sets with subgroup orders

```text
19, 31, 67.
```

Across every one of the twelve frozen subgroups satisfying

```text
n >= 271,
```

the exact result is

```text
0 power-affine decoders with at most two factors,
0 shifted-power decoders,
0 sparse-trinomial decoders.
```

The exhaustive monic-cubic screen was completed on nine fields in total. Six of
those are nontrivial frozen cases:

| p | subgroup order n | quotient points | exact monic cubic |
|---:|---:|---:|---:|
| 547 | 547 | 91 | 0 |
| 907 | 967 | 161 | 0 |
| 1051 | 1093 | 182 | 0 |
| 1087 | 271 | 45 | 0 |
| 1303 | 1249 | 208 | 0 |
| 1663 | 433 | 72 | 0 |

Thus the full monic-cubic class is negative on every screened nontrivial field
through `p=1663`.

## Capacity diagnostics

The result JSON records

```text
log2(number of nominal classes) - number of quotient bits
```

for each grammar. This is only a random-target union-bound diagnostic. It is
not a p-value for the structured carry target and is not used to certify the
finite negative results.

For the largest case, the recorded values are approximately

```text
-634.99 for up to two power-affine factors,
-639.39 for shifted powers,
-639.39 for sparse trinomials.
```

The grammar is therefore extremely small relative to all sign tables on 670
quotient points, but counting alone does not exclude a special structured
target. The exact exhaustive search supplies the actual finite statement.

## Interpretation

The negative evidence now covers two distinct notions of simplicity:

1. low support in ordinary linear factors, from package 010;
2. high algebraic degree generated by a very small declared exponentiation and
   affine-combination circuit, from package 011.

Allowing arbitrary fitted field constants makes the finite negative stronger
inside each declared grammar. It also means that any future positive hit would
still require a uniform, scalable rule for generating its constants from the
public curve parameters. A table of fitted coefficients is finite
interpolation, not an algorithm.

## Claim boundary

This package does not exclude:

1. products of three or more power-affine factors;
2. general expression trees using nested addition, multiplication and inverse;
3. circuits using several intermediate quotient invariants;
4. irreducible factors of degree at least four on fields above the cubic
   threshold;
5. canonical p-adic constructions whose final output descends to the base
   field;
6. an asymptotic succinct circuit not represented by the frozen grammar.

No result here evaluates an unknown secp256k1 point, private scalar, wallet, or
external target. No sub-square-root ECDLP algorithm is established.

## Next gate

The next useful package should test uniformity rather than merely enlarging a
fitted grammar:

```text
DIRECT-GLV-UNIFORM-GRAMMAR-012
```

A candidate should use a fixed expression tree across all frozen fields and
constants drawn from a public vocabulary generated from

```text
0, 1, -1, 7, beta, lambda, p, n, p-n, p+n
```

by a small number of field operations. Training and held-out curves should be
separated. This directly tests whether the carry table is generated by a
uniform public rule rather than encoded in instance-specific coefficients.
