## 2. Finite Heisenberg model

Let `H=<G>` be cyclic of odd prime order `n`. A level-`n` theta structure identifies the relevant theta group with a finite Heisenberg extension generated by

```text
X, Z, central omega,
ZX=omega XZ,
omega^n=1.                                      (H1)
```

In the Schrödinger model with basis `e_j`,

```text
X e_j=e_(j+1),
Z e_j=omega^j e_j.                              (H2)
```

The public subgroup `H` supplies the shift direction `X`. To obtain the phase direction `Z`, one must select a dual `n`-torsion point `T` with

```text
e_n(G,T)=omega.                                 (H3)
```

Then for `Q=[k]G`,

```text
e_n(Q,T)=omega^k.                               (H4)
```

This is the full faithful dual character, not merely one hidden bit.

## 3. No bit-valued linear character on an odd cycle

A one-dimensional linear character of `H` is determined by the image of `G`, whose order divides `n`.

If its image is restricted to `{+1,-1}`, its order divides two. Since `n` is odd, the only possibility is the trivial character:

```text
boxed:
Hom(H,{+1,-1})={1}.                              (H5)
```

Therefore canonical scalar parity cannot arise as a homomorphic theta eigencharacter. It necessarily uses the nonperiodic canonical cut in the representatives `0,...,n-1`.

Every nontrivial complex or cyclotomic character

```text
k -> omega^(a k), a!=0 mod n                    (H6)
```

has full order `n`. There is no intermediate nontrivial two-state linearization.

## 4. Dimension cost of the standard theta representation

For a degree-`d` line bundle `L` on an elliptic curve, the translation stabilizer `K(L)` is the kernel of the polarization map. Under the standard principal-polarization identification it is `E[d]`.

If `H` of prime order `n` acts by theta translations on `H^0(E,L)`, then `H` is contained in `K(L)`, hence

```text
n divides d.                                    (H7)
```

Riemann-Roch on a genus-one curve gives

```text
dim H^0(E,L)=d                                  (H8)
```

for positive degree. Consequently a standard section space carrying the full order-`n` translation action has

```text
boxed:
dim H^0(E,L)>=n.                                (H9)
```

For secp256k1 this is an explicit state of roughly `2^256` coordinates, not a sub-square-root representation.

This is a representation-size obstruction for the standard theta model, not a universal arithmetic-circuit lower bound against black-box evaluation of one special matrix coefficient.

## 5. Linearization ambiguity is the dual character group

Fixing the projective translation action does not fix a linear lift. Two lifts differ by a character of `H`:

```text
lift_2(P)=chi(P) lift_1(P),
chi in Hom(H,mu_n).                              (H10)
```

For prime order `n`, the ambiguity group has `n` elements. Any nontrivial choice is a full order-`n` dual character.

Thus a proposed generator-sensitive metaplectic lift must explain where its element of `Hom(H,mu_n)` comes from. If supplied as advice, a dual point, or a table of phases, that data must be charged.

Package 028 reached the same duality boundary from ratios of multiplicative splittings. Package 053 identifies it inside the standard Heisenberg representation itself.

## 6. Metaplectic intertwiners do not create missing data

A metaplectic operator intertwines two presentations of the same Heisenberg representation. Once the two theta structures and their linearizations are fixed, it is an invertible change of basis, projectively determined up to a scalar.

A public point-independent intertwiner can:

```text
rotate shift coordinates into phase coordinates,
apply finite Fourier transforms,
apply chirp multipliers,
permute Lagrangian splittings.
```

It cannot choose the missing dual character from the public cyclic line `H` alone. If a normalization depending on `G` or `Q` supplies that choice, the normalization itself is the candidate decoder and must be analyzed independently.

## 7. Full dual symmetrization loses the scalar

Suppose no dual generator is chosen and one symmetrizes over all nonzero characters. For `k!=0`, multiplication by `k` permutes the nonzero residues, so

```text
sum_(a=1)^(n-1) omega^(a k)
 =sum_(a=1)^(n-1) omega^a
 =-1.                                             (H11)
```

The fully dual-invariant trace is constant on every nonidentity point.

Weighted symmetrizations may retain other multiplicative scalar characters. The quadratic weighting gives the Legendre bit isolated in packages 034-042, but that route requires a second classical hidden-shift breakthrough and is not canonical parity.

Thus the standard alternatives are:

```text
choose one dual character       -> full omega^k phase,
sum all dual characters         -> constant,
quadratic weighted sum          -> Legendre bit,
bit-only homomorphic character  -> trivial.       (H12)
```

None supplies `Y_G(x(Q))/y(Q)=(-1)^k`.

## 8. secp256k1 dual field obstruction

For secp256k1 the public order certificate from the dual-orbit packages gives

```text
ord_n(p)=(n-1)/6,
p^((n-1)/12)=-1 mod n.                           (H13)
```

A concrete nonzero dual `n`-torsion point therefore lives over an extension of degree `(n-1)/6`, approximately `2^253.4`.

The theta structure cannot avoid this by naming only the dual line: its unoriented `+/- C3` Frobenius orbit still has degree `(n-1)/12`, approximately `2^252.4`.

Again this is a field-of-definition obstruction to explicit standard representation, not a proof against every compressed circuit.
