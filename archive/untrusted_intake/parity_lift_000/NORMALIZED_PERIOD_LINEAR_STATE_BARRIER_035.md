# NORMALIZED-PERIOD-LINEAR-STATE-BARRIER-035

Date: 2026-08-12

Status: **exact recurrence and finite-field state tradeoff; scoped no-go for explicit translation-linear blackboxes**.

No external point, private key, wallet, or production-sized discrete-log target is accepted. This package constructs no carry, hard-R3, parity, or ECDLP decoder.

## 1. Input from the normalized-period line

Let

```text
zeta=zeta_n,
C3={1,lambda,lambda^2},
A_m=sum_(a in C3) (zeta^(a*m)-zeta^(-a*m)),
U_m=A_m/A_1.
```

For `Q=[m]G`, the anti-Frobenius normalization identifies

```text
U_G(Q)=U_m,
g_G(Q)=g_G(G)*sign(U_m).
```

The sequence is exact, generator-sensitive, invariant under `m -> lambda*m`, and odd under `m -> -m`. The missing operation is public evaluation from `Q` without recovering `m` or constructing the cyclotomic period field.

This package asks whether the short recurrence visible in this sequence yields a compact blackbox.

## 2. Exact degree-six recurrence

Put

```text
r1=zeta,
r2=zeta^lambda,
r3=zeta^(lambda^2),
r1*r2*r3=1,

s=r1+r2+r3,
t=r1^(-1)+r2^(-1)+r3^(-1).
```

The six characteristic roots of `A_m` and `U_m` are

```text
r1,r2,r3,r1^(-1),r2^(-1),r3^(-1).
```

Their characteristic polynomial is

```text
M(X)
 =(X^3-sX^2+tX-1)(X^3-tX^2+sX-1)

 =X^6-(s+t)X^5+(st+s+t)X^4
   -(s^2+t^2+2)X^3
   +(st+s+t)X^2-(s+t)X+1.
```

Therefore

```text
U_(m+6)
 -(s+t)U_(m+5)
 +(st+s+t)U_(m+4)
 -(s^2+t^2+2)U_(m+3)
 +(st+s+t)U_(m+2)
 -(s+t)U_(m+1)
 +U_m
 =0.                                                    (R6)
```

So a recurrence of order six exists. The relevant question is the field required to represent its coefficients.

## 3. Frobenius closure of the six roots

Let

```text
d=ord_n(p),
q=p^e,
m_e=ord_n(q)=d/gcd(d,e),
C6={+/-1,+/-lambda,+/-lambda^2}.
```

Consider an exact recurrence with coefficients in `F_(p^e)`. If its annihilator polynomial is `P(X)`, linear independence of the six distinct exponential sequences implies

```text
P(zeta^a)=0 for every a in C6.
```

Since the coefficients of `P` lie in `F_(p^e)`, every `p^e`-Frobenius conjugate is also a root. Hence `P` must vanish on

```text
C6*<p^e>.
```

Conversely, the monic polynomial having precisely this Frobenius-closed root set annihilates `U_m`. Thus the exact minimum linear recurrence order over `F_(p^e)` is

```text
r_e
 =|C6*<p^e>|
 =6*m_e/|C6 intersection <p^e>|.                       (L1)
```

This is the precise rank versus coefficient-field-degree tradeoff. A low recurrence order is obtained only after the coefficient field absorbs most of the cyclotomic orbit.

## 4. secp256k1 specialization

For the fixed secp256k1 public parameters, the prior exact certificate gives

```text
d=ord_n(p)=(n-1)/6,
p^(d/2)=-1 mod n,
d mod 6=4.
```

Because `d` is not divisible by three, `<p>` contains no element of order three. Therefore for every `e`,

```text
|C6 intersection <p^e>| <= 2.
```

Equation `(L1)` gives

```text
r_e >= 3*m_e
     = 3*d/gcd(d,e).
```

Counting one `F_(p^e)` word as `e` base-field words,

```text
e*r_e
 >= 3*e*d/gcd(d,e)
 >= 3*d
 = (n-1)/2.                                            (L2)
```

The bound is attained at the half-Frobenius fixed field:

```text
e=d/2,
p^e=-1 mod n,
r_e=6,
e*r_e=3*d=(n-1)/2.
```

Thus the order-six recurrence is exact but not compact. Its six coefficients and six state entries live over an extension of degree `d/2`.

At the opposite endpoint, over the base field itself,

```text
e=1,
r_1=3*d=(n-1)/2.
```

Moving between these endpoints exchanges recurrence rank for coefficient-field degree without reducing the total base-field state below a quantity linear in `n`.

## 5. Arbitrary nonlinear readout from a linear state

The previous section assumes that `U_m` is a linear output of the recurrence state. A broader blackbox may maintain a state

```text
v_m=T^m v_0 in (F_(p^e))^r
```

and apply an arbitrary nonlinear readout to `v_m`.

If the readout equals the nonconstant period-orientation sequence, then the state orbit cannot have period one. Its period divides the prime `n`, so it must have period `n`.

On the cyclic submodule generated by `v_0`, the minimal polynomial of `T` therefore contains a nontrivial irreducible factor of the prime cyclotomic polynomial `Phi_n`. Every such factor over `F_(p^e)` has degree

```text
m_e=ord_n(p^e)=d/gcd(d,e).
```

Consequently

```text
r >= m_e,

e*r >= e*d/gcd(d,e) >= d=(n-1)/6.                    (S1)
```

The readout may be arbitrary. The lower bound comes from the explicit translation-linear state needed to support an orbit of prime period `n`.

This closes the class

```text
finite-field state + fixed linear update under Q -> Q+G
+ exact arbitrary readout.
```

It does not close a direct nonlinear coordinate circuit that does not maintain such a state.

## 6. Relation to dual-character linear support

The earlier dual-character package proved that an exact linear additive-character expansion of the carry itself requires all `n-1` nonzero Fourier frequencies.

The present result is different:

```text
direct carry:
  full linear Fourier support;

normalized period:
  only six splitting-field frequencies,
  but Frobenius descent forces a linear rank/field-degree product.
```

The two statements close complementary linear mechanisms. Neither is a lower bound for general nonlinear algorithms.

## 7. Frozen replay

`normalized_period_linear_state_barrier.py` performs two independent finite checks.

### Complex recurrence replay

On all fifteen frozen prime-order `j=0` toy subgroups it verifies equation `(R6)` cyclically at every scalar index.

```text

recurrence checks:                          14,313
maximum recurrence residual:                < 7e-11
maximum coefficient imaginary residual:     < 1e-15
```

### Exact Frobenius-closure arithmetic

Fourteen cases have `gcd(p,n)=1` and admit the cyclotomic finite-field phase. For every extension degree `1 <= e <= d`, the verifier checks

```text
m_e=d/gcd(d,e),
|C6*<p^e>|=6*m_e/|C6 intersection <p^e>|.
```

```text
exact extension-degree checks:              12,401
formula failures:                            0
```

The one excluded finite-field phase case has `p=n=547`; its complex degree-six recurrence is still replayed, but `p` is not a unit modulo `n` and `ord_n(p)` is undefined.

The secp256k1 block performs only fixed public integer arithmetic. It verifies the previously recorded order and half-Frobenius identities and records

```text
translation-linear arbitrary-readout state lower bound:
  d=(n-1)/6

linear-output recurrence lower bound:
  3d=(n-1)/2.
```

The secp256k1 subgroup is not enumerated.

## 8. Answer to package 035

```text
Does U_G have a short recurrence over a splitting field?          yes, order 6
Does that give a compact base-field evaluator?                    no
Exact linear recurrence state lower bound                         (n-1)/2 words
Translation-linear state with arbitrary readout lower bound       (n-1)/6 words
Public Q-only carry or hard-R3 decoder                             absent
Universal nonlinear circuit lower bound                           absent
Unconditional sub-square-root ECDLP algorithm                     absent
```

The correct interpretation is:

> Small recurrence order and small public representation are not the same. The order-six recurrence hides a coefficient field of degree `(n-1)/12`, and every explicit finite-field translation-linear realization retains linear total state.

## 9. Surviving class

The remaining coordinate question is genuinely nonlinear:

> Can the sign of `U_G(Q)` be computed directly from affine or projective coordinates by a uniform nonlinear arithmetic, p-adic, analytic, theta/sigma, or nonlocal EDS identity below the square-root baseline, without maintaining a translation-linear order-`n` state and without embedding an `(n-1)/6` orientation table or faithful dual character in its constants?

Package 036 attacks the first broad subclass: exact rational-coordinate functions followed by a quadratic character.
