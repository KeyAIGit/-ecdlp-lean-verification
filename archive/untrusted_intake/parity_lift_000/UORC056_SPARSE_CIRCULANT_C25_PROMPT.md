## Fixed input

C23 proves that addition, determinants, and resultants do not create branch information when all entries and coefficients are sign-blind.

C24 classifies the surviving non-fixed-resource problem. The only concrete addition-enabled family still structurally open after the prior symmetry screen is

```text
D_(a,b,c)(k)
  = det(a I + b T + c T^k)
  = Res_z(z^n-1, a+bz+cz^k),
```

where `T` is the order-`n` cyclic shift and `n` is an odd prime. The explicit Sylvester matrix has degree and state `Theta(n)`, so a positive result must not hide that representation.

Known exact exponent-triple symmetries are generated by the six Möbius transforms

```text
k,
1/k,
1-k,
1/(1-k),
(k-1)/k,
k/(k-1),
```

with corresponding permutations of `(a,b,c)`.

The previous bounded screen found no exact parity decoder, but the `a=b` stratum and fully asymmetric coefficient triples were not universally rejected by the first symmetry witnesses.

## Central target

For prime `n` and canonical representatives `1<=k<n`, determine whether there exists a public coefficient family

```text
(a_n,b_n,c_n)
```

with charged description size `o(sqrt(n))` such that an exact public extraction from

```text
D_(a_n,b_n,c_n)(k)
```

gives

```text
(-1)^k
```

for every admissible `k`, including all zero and collision cases, with complete cost

```text
C_preprocessing + C_advice + C_memory
+ C_representation + C_online
= O(n^(1/2-epsilon)).
```

A parity match only on a finite corpus is not sufficient.

## Mandatory attack order

### A. Exact symmetry group

Construct the full action generated by affine changes of the exponent triple `{0,1,k}`. Prove:

```text
which Möbius transforms preserve canonical parity,
which reverse it for n mod 4 and n mod 8 classes,
which coefficient stabilizers force D(k)=D(g.k),
which coefficient strata are immediately incompatible with parity.
```

Do not stop at the three equal-coefficient strata. Classify every stabilizer type of the `S3` action on `(a,b,c)`, including zeros and repeated coefficients.

### B. Orbit obstruction

For each coefficient stratum, search for one exact orbit collision

```text
D(k)=D(k')
```

with opposite canonical parity. If such a collision exists for all sufficiently large primes in a congruence class, prove it symbolically.

Separate:

```text

congruence-class obstruction,
finite-order exception.
```

### C. Fully asymmetric coefficients

For triples with trivial coefficient stabilizer, determine whether the six determinant values merely permute with the coefficients or whether a coefficient-invariant extraction can retain parity.

Any proposed extraction must specify whether it reads:

```text
the exact field value,
a quadratic character,
a fixed multiplicative character,
a trace or norm,
a coefficient-symmetric tuple of the six values.
```

If it uses several coefficient permutations, charge all queries and stored coefficients.

### D. Sparse resultant structure

Derive an exact representation that does not enumerate `n` roots of unity or build an `n` by `n` matrix. Candidate routes include:

```text
Euclidean reduction of z^n-1 by a+bz+cz^k,
subresultant recurrences,
companion-matrix compression,
transfer matrices indexed by the Euclidean algorithm of (n,k),
cyclotomic norm recurrences,
Mahler-measure style product identities only when made exact over finite fields,
lacunary resultant algorithms with explicit bit and field-operation cost.
```

A recurrence whose control flow or coefficient indices require the unknown `k` is not an evaluator from public `Q` unless a public group operation supplies those steps without recovering `k`.

### E. Public-Q realization

The scalar formula uses `T^k`. Explain exactly how the public point `Q=[k]G` supplies the corresponding operator or coefficient without materializing the entire regular representation.

Reject:

```text

all n-th roots of unity,
a hidden scalar k,
a degree-n polynomial supplied as advice.
```

### F. Branch law versus parity law

```text

```

or directly to the canonical oriented-root value. Do not infer branch sensitivity merely because the determinant is not covered by a prior factorization.
