## 2. The relevant Eisenstein ray class group

Let

```text
K=Q(sqrt(-3)),
O_K=Z[omega],
```

and let the public short CM element

```text
pi=a+b*omega
```

have Eisenstein norm

```text
N(pi)=n.
```

The prime `n` splits as `(pi)(pi_bar)`. The public subgroup `H` is the kernel line corresponding to one split prime.

Because `O_K` has class number one, the ray class group modulo `pi`, after the standard coprimality assumptions, is

```text
Cl_pi ~= (O_K/pi)^* / O_K^*
      ~= F_n^* / mu_6.                            (R1)
```

Its order is

```text
(n-1)/6.
```

For the secp256k1 branch

```text
n=1 mod 12,
```

all six CM units are quadratic residues modulo `n`. Therefore the scalar quadratic character descends to a well-defined index-two character

```text
chi_bar : Cl_pi -> {plus_or_minus 1}.             (R2)
```

Changing the marked generator by

```text
G -> [k]G
```

is exactly the corresponding ray-class/diamond action on the marked `pi`-torsion line. The hidden torus character of package 039 and the quadratic ray-class character are the same abstract character.

## 3. The j=0 Weber function

On

```text
E: y^2=x^3+7,
```

the automorphism group generated by

```text
(x,y)->(beta*x,y),
(x,y)->(x,-y)
```

has order six. The function

```text
h(P)=x(P)^3
```

is invariant under this full group and is a Weber function up to a fractional-linear normalization.

Let `C6=mu_6` denote the six scalar classes

```text
{plus_or_minus 1, plus_or_minus lambda, plus_or_minus lambda^2}.
```

Define the quadratic ray-class resolvent

```text
R_h(G)=sum_(u in F_n^*/C6) chi_n(u) h([u]G).      (R3)
```

This is well-defined because both `h([u]G)` and `chi_n(u)` are constant on each `C6` coset.

For `Q=[k]G`, multiplication by `k` permutes the quotient classes, so

```text
R_h(Q)=chi_n(k) R_h(G).                           (R4)
```

Whenever `R_h(G)` is nonzero,

```text
chi_n(k)=R_h(Q)/R_h(G).                           (R5)
```

## 4. Exact identification with the existing projector

Package 034 defined

```text
S_3(P)=sum_(a=1..n-1) chi_n(a)x([a]P)^3.
```

Each `C6` coset contributes six identical summands. Therefore

```text
S_3(P)=6 R_h(P).                                  (R6)
```

Thus the CM ray-class resolvent is not a new hidden-bit object. It is exactly the previously discovered scalar-Legendre projector written in class-field language.

This is the main loop-closing result of the package.

## 5. What standard class-field operations lose

The unweighted ray-class trace

```text
Tr_h(G)=sum_(u in F_n^*/C6) h([u]G)
```

is unchanged by every generator replacement `G->[k]G`.

The full norm and the square of the quadratic resolvent are likewise generator-blind:

```text
R_h([k]G)^2=R_h(G)^2.                             (R7)
```

The quadratic subfield of the ray class field has degree two, but this does not make the marked-point orientation automatic. Its two conjugate branches are `R_h(G)` and `-R_h(G)`, and a nonsquare generator change swaps them.

Explicit CM reciprocity determines how a known ray-class element acts on Weber or Siegel values. Here the unknown object is precisely the ray-class element carrying `G` to `Q`. Reciprocity supplies the transformation law `(R4)` but does not invert the marked-point action.

## 6. Dense character idempotent

In the regular representation of the ray class group, the projector to the quadratic isotypic line is

```text
e_chi=(1/|Cl_pi|) sum_(u in Cl_pi) chi_bar(u)^(-1)[u].
```

It has support on all

```text
(n-1)/6
```

ray classes. Applied to a Weber value, it produces `(R3)`.

This explains why standard trace or norm operations are compact but orientation-free, while the oriented quadratic resolvent is a dense character projection.

The dense support is not an arithmetic-circuit lower bound. A special `n`-dependent product formula or recurrence could in principle evaluate the same eigencomponent compactly.

## 7. Representation and degree boundary

A fixed-conductor or bounded-degree function cannot solve the problem uniformly for growing `n`.

If a rational function `f` on the elliptic curve satisfies

```text
f([k]G)=chi_n(k)
```

on all nonzero subgroup points, then `f^2-1` has at least `n-1` zeros, forcing

```text
deg(f) >= (n-1)/2.
```

On the `C6` quotient, an exact polynomial decoder has degree at least

```text
(n-1)/12.
```

Therefore a successful Weber, Siegel, theta, sigma, or elliptic-unit construction must have conductor or arithmetic degree growing with `n`, or must represent the high-degree object by a genuinely short special circuit.

The generic CM/Frobenius lower bound from package 039 still applies to any procedure that uses only group operations and known endomorphisms.
