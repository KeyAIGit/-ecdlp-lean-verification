# UORC056 successor prompt

## NEGATION-PAIRED-QUADRATIC-RESOLVENT-070

Continue from C19 without reopening closed constant-coefficient rational families.

### Fixed input

For the public endpoint gauge

```text
Z(P)=h_G(P)/h_G(P+G)
```

C19 proves the exact monic identity

```text
K(P)=Z(P)Z(-P)
    =(x(P)-x([a-1]G)) /
      ((x(P)-x(G))(x(P)-x([a]G))(x(P)-x([m]G))).
```

Thus `K` is public, point-negation-even, branch-even, has divisor support nine, numerator degree one, denominator degree three.

The remaining global ambiguity is still

```text
Z -> -Z.
```

### Central objects

For `i=0,1,2`, let

```text
Z_i(P)=Z(phi^i(P)),
K_i(P)=K(phi^i(P)),
S_i(P)=Z_i(P)+Z_i(-P),
D_i(P)=Z_i(P)-Z_i(-P).
```

Then

```text
S_i^2-D_i^2=4K_i,
Delta_i=S_i^2-4K_i=D_i^2.
```

Global branch change sends

```text
S_i -> -S_i,
D_i -> -D_i,
K_i -> K_i.
```

### Main target

Determine whether any uniform odd aggregate built from the paired quadratic data can be evaluated with fully charged cost

```text
C_preprocessing+C_advice+C_memory+C_representation+C_online
=O(n^(1/2-epsilon)).
```

A positive result must recover the unresolved global branch from public `E,G,Q`, not from a supplied square-root sign.

### Mandatory package A: exact pair algebra and fixed fields

Prove and replay:

```text
Tr_phi(S_i) is invariant under phi and point negation,
therefore lies in F_p(x^3)=F_p(y^2).

Tr_phi(D_i) is invariant under phi and anti-invariant under point negation,
therefore lies in y*F_p(x^3).
```

Record exact global rational signatures and endpoint divisors on the seven-curve corpus and public generator replacements.

### Mandatory package B: Dickson recurrence

Define

```text
U_0=2,
U_1=S,
U_j=Z^j+Z(-P)^j.
```

Prove

```text
U_j=S*U_(j-1)-K*U_(j-2).
```

Classify branch covariance by `j` and determine whether `Tr_phi(U_j)` can have divisor collapse for arbitrary high `j` with short recurrence description.

Do not confuse short index recurrence with cheap construction of the hard base value `S`.

### Mandatory package C: quadratic extraction gate

Treat

```text
X^2-S_i X+K_i=0
```

as a genuine quadratic orientation problem.

A claimed evaluator must specify how it chooses the sign of

```text
sqrt(S_i^2-4K_i)
```

without receiving the target branch as advice. Show explicitly whether the square-root sign is equivalent to the original global `mu_2` ambiguity.

### Mandatory package D: interaction with adjacent products

C15 supplies compact products

```text
A(P)=Z(P)Z(P+G).
```

Analyze the graph and algebra generated by public pair products

```text
Z(P)Z(-P),
Z(P)Z(P+G).
```

Required checks:

1. all equations remain invariant under global `Z -> -Z`;
2. classify connected components and cycle parity in the universal product graph;
3. determine the minimum number of public edge products needed to select a canonical value;
4. distinguish graph reconstruction up to sign from actual sign selection;
5. test whether curve-specific rational relations beat the universal graph bound.

### Mandatory package E: bounded nonlinear synthesis

Use a predeclared grammar over

```text
K_i,
S_i^2,
D_i^2,
K_i/K_j,
adjacent products,
elementary symmetric functions,
Dickson polynomials U_j.
```

Split the public corpus into discovery, validation and held-out sets before screening. Charge every coefficient and every branch choice. Reject formulas that become undefined at collisions unless they include a public regularization rule.

### Mandatory package F: scoped theorem

Prove at least one broad statement, for example:

```text
pair-product-only circuits cannot select the global sign;
```

or

```text
bounded-depth quadratic extraction with branch-even radicands preserves one global mu_2 ambiguity;
```

or

```text
Dickson recurrences do not reduce divisor support unless the base paired sum S already has a compact evaluator.
```

State the exact grammar and cost model. Do not claim an unrestricted arithmetic-circuit lower bound.

### Positive gate

A positive candidate receives credit only if it includes:

```text
exact identity on every nonexceptional subgroup point,
collision and pole handling,
generator covariance,
branch-odd output,
no hidden square-root advice,
full cost accounting,
reproducible implementation,
held-out validation,
strictly sub-square-root total complexity.
```

### Negative gate

A negative result must provide:

```text
an explicit circuit grammar,
a proved invariant or lower bound,
exact replay,
a precise list of classes not covered.
```

Finite failure alone is support evidence, not an unrestricted impossibility theorem.
