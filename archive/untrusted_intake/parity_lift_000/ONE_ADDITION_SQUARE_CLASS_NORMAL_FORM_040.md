# ONE-ADDITION-SQUARE-CLASS-NORMAL-FORM-040

Date: 2026-08-12

Status: exact normal-form reduction and exhaustive toy rejection; no carry executor identity obtained.

## Exact class

For a circuit starting from public affine coordinates `x(Q), y(Q)` and field constants, using multiplication, inversion, powering, and exactly one addition/subtraction, its quadratic square class on a subgroup with nonzero `x,y` has the form

```text
F(Q) = kappa * x(Q)^u * y(Q)^v * (1 + c*x(Q)^a*y(Q)^b),
```

where `u,v in {0,1}`, `a,b mod (p-1)`, `c in F_p`, and only the quadratic character of `kappa` matters.

The requested identity is

```text
chi_p(F(Q)) = g_G(Q)
```

for every nonzero subgroup point.

- `(p,n,G)=(43,31,(2,12))`: 1,322 exact formulas.

## Conclusion

No scalable one-addition executor identity was found. This is stronger than a bounded-degree search because all exponents modulo `p-1` are included, including huge exponents generated by short addition chains.

This does not logically rule out a secp256k1-specific exceptional identity. It removes broad, unguided search in the one-addition monomial class from the priority queue.

The next genuinely different coordinate class has two additive innovations, but must first be reduced to an exact normal form and searched with symmetry-aware methods rather than blind brute force.
