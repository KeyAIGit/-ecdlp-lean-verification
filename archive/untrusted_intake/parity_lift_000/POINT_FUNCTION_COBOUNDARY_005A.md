# POINT-FUNCTION-COBOUNDARY-005A

Date: 2026-08-11

Status: **isolated, non-executable theorem-first package with frozen toy replay**.
This package targets no external point, key, wallet, or production discrete-log
instance. It changes no canonical Research Engine state, authorizes no attack
run, and makes no asymptotic-improvement claim.

## 1. Why this package follows NONLOCAL-ODD-ANCHOR-004

Let `G` generate a cyclic subgroup of odd prime order `n`, and write

```text
Q = [k]G,
rho_G(Q) = chi(psi_k(G)),
C(P) = chi(phi_raw(P)).
```

On the secp256k1 normalization,

```text
C(Q) = (-1)^k rho_G(Q).
```

`NONLOCAL-ODD-ANCHOR-004` isolated the hidden GLV-orbit aggregate

```text
R3(Q) = rho_G(Q) rho_G(phi(Q)) rho_G(phi^2(Q))
```

and the canonical GLV carry `gamma(Q)`. It showed that the first absolute
torsion jet has an odd hidden residue product in its raw transformation law,
but its orbit normalization uses exactly the same carry character as the public
point-function orbit norm. The equations are therefore dependent.

The next question is whether a larger family of ordinary division-polynomial
sections can produce a genuinely different equation.

This package answers that question for every finite multiplicative product or
ratio of ordinary rank-one division-polynomial values evaluated at public point
maps.

## 2. Raw point-function transport law

The branch uses the raw point-function convention

```text
phi_raw([m]P) = phi_raw(P)^(m^2) psi_m(P).       (R)
```

Here `P` is a nonzero point of order `n`, `gcd(n,q-1)=1`, and `[m]P` is nonzero.
The distinction between this raw law and the printed `m^2-1` normalization in
Lauter--Stange remains an explicit source-review blocker elsewhere in the
branch. The statements below are conditional on (R), and the frozen replay
independently tests their concrete finite-field consequences.

Taking quadratic characters in (R) gives the central identity:

```text
boxed:
chi(psi_m(P)) = C([m]P) C(P)^(m^2).             (C1)
```

Since `C(P)` is a sign,

```text
C(P)^(m^2) = C(P)^(m mod 2).
```

Every factor on the right of (C1) is directly computable from public points.

## 3. Complete near-period collapse

Let

```text
m = r*n + a.
```

Because `[n]Q=O`,

```text
[m]Q = [a]Q.
```

Since `n` is odd,

```text
m^2 = m = r+a  (mod 2).
```

Therefore (C1) gives the exact family law

```text
boxed:
chi(psi_(r*n+a)(Q))
  = C([a]Q) C(Q)^((r+a) mod 2).                 (C2)
```

This contains the previously derived `n+1` and `n-1` identities as two special
cases. It also covers every public index of the forms

```text
n +/- a,
2*n +/- a,
r*n + a,
```

provided the resulting division-polynomial value is nonzero.

Thus extending the bounded screen from `n +/- 4` to `n +/- 5`, `n +/- 6`, or any
other finite radius cannot create an independent residue equation. The complete
ordinary near-period family is already a public point-function coboundary.

## 4. Finite multiplicative-section theorem

Let `T_i(Q)` be arbitrary efficiently computable public point maps into the
same prime-order subgroup. Let `m_i` and `e_i` be public integers, and assume

```text
T_i(Q) != O,
[m_i]T_i(Q) != O
```

for every retained factor. Define

```text
F(Q) = product_i psi_(m_i)(T_i(Q))^(e_i).
```

Applying (C1) factor by factor yields

```text
boxed:
chi(F(Q))
  = product_i
      C([m_i]T_i(Q))^(e_i)
      C(T_i(Q))^(e_i*m_i^2).                   (C3)
```

Negative exponents cause no problem on the nonvanishing domain. Under a
quadratic character, only each exponent modulo two survives.

### Consequence

The quadratic character of every such multiplicative section belongs to the
algebra generated by publicly evaluable point-function characters `C(R)` at
publicly computable points `R`.

Therefore a finite product or ratio of ordinary division-polynomial values does
not enlarge the available binary information. Its hidden-residue expansion may
contain an odd number of `rho` factors, but the accompanying normalization is
already exactly represented by public `C` factors.

This is stronger than saying that an observable is public. It identifies the
precise public character algebra to which the observable belongs and shows that
it cannot supply a second independent normalization equation.

## 5. GLV-orbit norm corollary

Let `phi` be the order-three `j=0` GLV automorphism. It commutes with scalar
multiplication. Define

```text
C3(P) = C(P) C(phi(P)) C(phi^2(P)).
```

For one ordinary division-polynomial section,

```text
N_m(P)
  = product_(j=0)^2 chi(psi_m(phi^j(P))).
```

Using (C1) and commutation of `phi` with `[m]` gives

```text
boxed:
N_m(P) = C3([m]P) C3(P)^(m mod 2).              (G1)
```

More generally, for a homogeneous multiplicative section

```text
A(P) = product_i psi_(m_i)([a_i]P)^(e_i),
```

its GLV-orbit norm is

```text
boxed:
product_(j=0)^2 chi(A(phi^j(P)))
  = product_i
      C3([m_i*a_i]P)^(e_i)
      C3([a_i]P)^(e_i*m_i^2).                  (G2)
```

Thus every GLV-orbit norm in this class lies in the already-public algebra
generated by `C3` on known scalar multiples of `P`.

### Consequence for GLV-CARRY-SEPARATION-005

Ordinary multiplicative division-polynomial sections cannot provide the sought
second orbit equation with an independent GLV carry multiplier. Any apparent
new odd-residue law is an exact `C3` coboundary.

This does not prove that the family of public values `C3([a]Q)` itself cannot be
used by some different algorithm to decode `R3(Q)`. It proves that wrapping
those values in finite products or ratios of ordinary `psi_m` sections adds no
new equation.

## 6. Nonvanishing and exceptional loci

The theorem is binary only where every factor is nonzero.

For a nonzero point `P` of prime order `n`,

```text
psi_m(P)=0  iff  n divides m.
```

Such an index is public and vanishes uniformly on the nonzero subgroup, so it
is not a secret-dependent bit. A public point map `T_i(Q)` may nevertheless hit
`O` on an exceptional target set. Those cases must be treated explicitly by a
candidate construction and are outside the nonvanishing theorem.

A bounded exceptional set cannot silently be promoted into a global parity
oracle.

## 8. What this closes

Closed inside the stated assumptions:

```text
chi(psi_m(P)),
products and ratios of finitely many chi(psi_m(T(Q))),
all ordinary near-period sections psi_(r*n+a)(Q),
GLV-orbit norms of homogeneous multiplicative division-polynomial sections.
```

These classes cannot supply a new character equation beyond public point
function values.

## 9. What remains genuinely open

This package does not cover operations for which the quadratic character cannot
be distributed factor by factor:

1. sums or linear combinations of division-polynomial values;
2. determinants, resultants, or Wronskians containing additive cancellation;
3. higher torsion jets and derivatives;
4. theta or sigma monodromy with a nonstandard global trivialization;
5. p-adic analytic continuation with an exact public evaluation and precision
   theorem;
6. an algorithm exploiting many public `C` or `C3` values without first
   packaging them as ordinary multiplicative sections.

Accordingly the next constructive question is no longer whether a larger index
or a longer product helps. It is:

> Does there exist an efficiently evaluable **non-multiplicative** section whose
> GLV-orbit character is not a point-function coboundary and whose hidden law
> separates `R3(Q)` from the canonical GLV carry `gamma(Q)`?

A minimal algebraic candidate should therefore be searched first among
additive two-term combinations, determinants, or derivative pairings rather
than among additional products of `psi_m` values.

## 10. Claim boundary

This is not a general lower bound for nongeneric ECDLP algorithms. It is a
mechanism-level closure for a precisely defined multiplicative class.

The load-bearing raw transport law remains tied to the branch's unresolved
source-normalization audit. No result in this package should be promoted as
canonical before that identity receives independent source/CAS review.

No sub-square-root EDS-residue decoder or secp256k1 discrete-log algorithm has
been obtained.
