# DIRECT-GLV-CARRY-DESCENT-010

Status: **isolated bounded research package; no production target**.

## Question

Let `H=<G>` be a frozen prime-order subgroup on a `j=0` curve

```text
E/F_p : y^2 = x^3 + 7,
phi(x,y) = (beta*x,y),
phi(G) = [lambda]G,
lambda^2 + lambda + 1 = 0 mod n.
```

For `Q=[k]G`, write the canonical representatives of

```text
k, lambda*k, lambda^2*k
```

in `{1,...,n-1}`. Their sum is either `n` or `2n`. The GLV carry sign is

```text
g(Q) = -1  when the sum is n,
g(Q) = +1  when the sum is 2n.
```

The surviving direct-descent question is whether a public, succinct base-field
function can output `g(Q)` without recovering `k`.

## Quotient reduction

The order-three GLV map fixes `y` and `x^3`. On

```text
F_p(E) = F_p(x,y),  y^2=x^3+7,
```

the invariant field is

```text
F_p(E)^<phi> = F_p(y) = F_p(x^3,y).
```

Negation sends `y -> -y`. Hence a GLV-invariant rational function that is odd
under `Q -> -Q` has the form

```text
F(Q) = y(Q) * R(y(Q)^2)
     = y(Q) * R(x(Q)^3).
```

Every frozen field in this package satisfies `p = 3 mod 4`, so
`chi(-1)=-1`. Therefore

```text
chi(y(Q) * R(x(Q)^3))
```

has exactly the required symmetry:

```text
phi-invariant and anti-invariant under Q -> -Q.
```

Put

```text
z(Q)=x(Q)^3,
h(Q)=g(Q)*chi(y(Q)).
```

Then `h` is constant on the six-element orbit generated by `phi` and negation,
and the decoder problem becomes

```text
chi(R(z(Q))) = h(Q)
```

on `(n-1)/6` quotient points. In all fifteen frozen cases, `z` separates those
six-element quotient orbits exactly.

## Exhausted finite classes

`direct_glv_carry_descent_screen.py` exactly checks two classes.

### 1. Split squarefree support at most four

It exhausts

```text
R(z)=u * product_{j=1}^d (z-c_j),
0 <= d <= 4,
c_j in F_p distinct,
chi(u) in {+1,-1}.
```

The search is exact. Degrees at most three use direct XOR lookup on the binary
character vectors. Degree four uses meet-in-the-middle with two deterministic
linear 64-bit projections. Every full equality survives both projections;
projection collisions can only create extra candidates, and every candidate is
replayed against the complete bit vectors.

### 2. Total rational square-class degree at most two

For a rational expression `A(z)/B(z)`, quadratic character satisfies

```text
chi(A/B)=chi(A*B)
```

away from zeros. Thus every rational square class with

```text
deg(A)+deg(B) <= 2
```

is represented, up to a constant square class, by

```text
u * (z^2 + a*z + b).
```

The program exhausts every `a,b in F_p` and both values of `chi(u)`. This also
covers irreducible quadratics and linear-fractional ratios of total degree two.

## Frozen result

There are exact finite interpolants only on the three smallest quotient sets:

| subgroup order | quotient points | smallest observed class |
|---:|---:|---|
| 19 | 3 | constant square class |
| 31 | 5 | two split factors / quadratic |
| 67 | 11 | two split factors / quadratic |

For every one of the twelve frozen subgroups with

```text
n >= 271,
```

the exact result is

```text
no split decoder with d <= 4,
no rational square class with deg(A)+deg(B) <= 2.
```

The largest checked subgroup has order `4021` and `670` quotient points.

## Full linear-factor rank

For every frozen case, the complete family

```text
c -> chi(z-c),  c not among the sampled z-values,
```

has full `F_2` rank equal to the number of quotient points. Therefore a
high-support split interpolation always remains possible on these finite sets.
This is important: the experiment does **not** prove non-existence of `R`.
It separates small formulas from generic finite interpolation.

Deterministic and randomized Gaussian bases produce support upper bounds that
grow to `267` and `313` factors on the two largest cases. These values are not
minimum-support certificates, but they are qualitatively incompatible with a
fixed tiny factor formula.

## Interpretation

This closes two natural first escape classes beyond the theta/cyclotomic
boundary:

```text
small products of quotient-coordinate characters,
and all total-degree-two rational square classes.
```

It does not close:

1. irreducible factors of degree at least three;
2. high-degree sparse polynomials such as `z^e+a`;
3. low-depth arithmetic circuits whose algebraic degree is large;
4. canonical p-adic constructions with a base-field output;
5. any asymptotic class not represented by the frozen finite grammar.
