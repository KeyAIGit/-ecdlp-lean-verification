# FROBENIUS-DELTA-CHARACTER-SELECTOR-C064

Date: 2026-08-13

Status: **on the ordinary canonical CM lift, the linear arithmetic-differential character supplies no independent orientation beyond the C060/C061 arithmetic jet. It vanishes on the canonical torsion section, and its value on the Teichmuller section is a public scalar multiple of the unique formal-kernel correction.**

No external point, private key, wallet, or production-sized discrete-log target is accepted.

## 1. Canonical delta structure

An ordinary canonical lift is characterized by the existence of its canonical delta/Frobenius structure. For the fixed `j=0`, `p=1 mod 3` CM lift, the Frobenius lift commutes with the CM automorphism.

Arithmetic jet theory attaches additive delta-characters to the lifted elliptic curve. In the Frobenius-lift case the associated rational delta-character/isocrystal is one-dimensional rather than the full two-dimensional crystalline object.

Thus the first linear arithmetic-differential direction is unique up to a public scalar.

## 2. Torsion vanishing

Let

```text
tau:H->E(Z_p)
```

be the canonical prime-to-p torsion lift. Any additive delta-character `Psi` satisfies

```text
Psi([n]tau(Q))=n Psi(tau(Q)).
```

Since `[n]tau(Q)=O` and `n` is p-adically invertible,

```text
boxed:
Psi(tau(Q))=0.                                   (D1)
```

Therefore the canonical delta-character does not directly evaluate a nonzero bit on the lifted subgroup.

## 3. Evaluation on the Teichmuller section

Write, as in C062,

```text
tau(Q)=s(Q)+b(Q),
b(Q) in the formal kernel.                        (D2)
```

Additivity and `(D1)` give

```text
Psi(s(Q))=-Psi(b(Q)).                             (D3)
```

On the first formal-kernel layer modulo `p^2`, every nonzero additive character is a public scalar multiple of the formal coordinate. Hence

```text
Psi(s(Q)) mod p
 =c_E * epsilon_n(Q)                             (D4)
```

for one public curve-dependent nonzero scalar `c_E`, where `epsilon_n` is the arithmetic division jet from C061.

Thus the linear Frobenius delta-character is not a new observable. It is a coordinate-free interpretation of the already constructed torsion-lift correction.

## 4. CM eigencomponent

Because Frobenius and the CM automorphism commute, the character has one known CM eigenweight. The transformation law therefore agrees with C061:

```text
Psi(s(phi Q))=beta Psi(s(Q)),
Psi(s(-Q))=-Psi(s(Q)).                            (D5)
```

No second independent eigencomponent exists at the linear-character level on the canonical lift.

## 5. Higher linear delta expressions

Frobenius iterates and public linear combinations of the same rank-one delta-character remain inside the module generated by `Psi`. At fixed precision they produce public transforms of the same Witt/arithmetic-jet data already tested in C061-C063.

A genuinely new mechanism must therefore be nonlinear in arithmetic jets or use additional arithmetic directions/level data. Calling another Frobenius iterate a new character does not create an independent selector.

## 6. Closed class

Closed by this package:

```text
a linear order-one Frobenius delta-character as an independent carry bit,
linear combinations of its Frobenius iterates at fixed precision,
claims that canonical delta structure avoids torsion vanishing,
claims that the first delta-character is independent of the C060 splitting correction.
```

## 7. What remains open

Not closed:

1. nonlinear arithmetic-differential functions of several jet levels;
2. a genuinely multi-direction arithmetic PDE character with all directions publicly defined from the fixed instance;
3. a delta-theta or delta-sigma object not factoring through the additive character;
4. a compact CM/ray-class identity producing the generator orientation directly.

## 8. Successor

The first admissible nonlinear object is

```text
DELTA-THETA-WRONSKIAN-C065.
```

It must combine a theta/section value with its arithmetic Frobenius jet in an alternating Wronskian so that common scalar normalizations cancel. The pass must first prove whether such a Wronskian is genuinely independent of `epsilon_n`, or whether rank-one delta-character theory forces another coboundary collapse.

## Sources and boundary

This package uses the canonical-lift/delta-structure characterization of ordinary abelian varieties and the rank-one delta-character behavior in the Frobenius-lift elliptic case. It is a scoped mechanism reduction, not a universal nonlinear arithmetic-circuit lower bound, and no carry or scalar-recovery algorithm is obtained.
