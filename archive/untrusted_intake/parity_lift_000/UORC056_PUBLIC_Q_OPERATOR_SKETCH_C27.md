## 2. Base-field linear quotient states

Let `n` be prime, `p` not divide `n`, and

```text
rho:C_n -> GL_d(F_p).
```

For a generator matrix `A=rho(t)`, the minimal polynomial divides

```text
X^n-1=(X-1)Phi_n(X).
```

If the representation is nontrivial, the image of `t` has order `n`. Hence the
minimal polynomial contains an irreducible factor of `Phi_n`. Every such factor
over `F_p` has degree `ord_n(p)`. Therefore

```text
boxed:
d >= ord_n(p).                                      (C27.1)
```

A representation below this dimension is trivial, so every deterministic state
that factors only through `rho(G),rho(Q)` is independent of `k`.

A one-dimensional eigencharacter over `F_(p^d)` does not evade the bound. The
extension degree is itself `ord_n(p)`, so base-field storage has only changed
form.

## 3. Fixed sparse trace sketches

Consider fixed public channels

```text
M_i(k)=Tr(sum_((a,b) in A_i) c_(i,a,b) T_G^a T_Q^b).
```

Supports and coefficients are independent of hidden `k`, and every expanded
monomial is charged. Since `T_Q=T_G^k`,

```text
boxed:
Tr(T_G^a T_Q^b)
=
n, if a+bk=0 mod n,
0, otherwise.                                      (C27.2)
```

For `b!=0`, one atom is exceptional at most one nonzero scalar,
`k=-a/b mod n`. Let `E` be the union of all exceptional residues. Outside `E`,
the complete transcript is constant. Coefficient cancellation can only shrink
`E`.

The nonzero canonical domain contains `(n-1)/2` even and `(n-1)/2` odd
scalars. If `|E|<(n-1)/2`, neither full parity fibre is covered. An even and an
odd scalar remain outside `E`, with identical transcripts and different
parity. Hence

```text
boxed:
number of distinct charged exceptional ratios
>= (n-1)/2.                                        (C27.3)
```

For secp256k1 this is

```text
57896044618658097711785492504343953926418782139537452191302581570759080747168,
```

a 255-bit quantity.

The bound is exact. A single channel containing `T_G^(-r)T_Q` for every odd
canonical `r` is nonzero exactly on odd `k`. It uses `(n-1)/2` atoms, which is
the forbidden half-orbit orientation table itself.

## 4. Coordinate-sparse bilinear and Krylov probes

Let

```text
B_i(k)=u_i^T T_G^(a_i) T_Q^(b_i) v_i,
L_i=supp(u_i),
R_i=supp(v_i).
```

A probe can be nonzero only if

```text
a_i+b_i k=l-r mod n
```

for some `l in L_i`, `r in R_i`. For `b_i!=0`, each pair `(l,r)` determines at
most one scalar. Thus probe `i` has at most `|L_i||R_i|` exceptional residues.
The same constant-outside argument gives

```text
boxed:
sum_i |supp(u_i)| |supp(v_i)| >= (n-1)/2.         (C27.4)
```

This bound is also exact. Take `v=e_0` and let `u` be supported on all odd
coordinates. The query decodes parity, but stores the complete odd half-orbit.

The result closes coordinate-sparse Krylov or Wiedemann-style projections when
all support coordinates and cross pairs are charged. It does not close a
structured dense vector produced by a genuinely compact nonlinear rule.

## 5. Expanded Newton-moment corollary



