## Fixed input

C21 reduces the unresolved branch to

```text
R(y)=H(y)/H(-y),
R(y)R(-y)=1,
R(infinity)=1.
```

For every explicit half-divisor, dense coefficient pair, Padé representation, continued fraction, half-gcd object, subproduct tree, explicit modular-composition module, norm-factor list, or `o(n)`-degree alternative factor, C21 proves a linear charged representation boundary.

The remaining opening is not another explicit representation. It is an implicit arithmetic program that evaluates the canonically normalized value at one public query point without constructing `H`.

## Central target

Given public `E,G,Q,n`, compute the branch-odd value represented by `R(Q)` or an equivalent exact orientation bit with total cost

```text
C_preprocessing + C_advice + C_memory
+ C_representation + C_online
= O(n^(1/2-epsilon)).
```

The rule `R(infinity)=1` may be used to canonicalize a candidate class, but it is not itself a construction of that class.

## Mandatory attack order

### A. Implicit straight-line program

Search for a uniform arithmetic circuit that evaluates `H(y_Q)/H(-y_Q)` while never materializing the coefficients or divisor of `H`. Candidate leaves may include public curve coordinates, GLV maps, constant-offset Miller quotients, division-polynomial values at public indices, derivatives, residues, and low-degree norms.

Every n-dependent leaf and precomputed state is charged. A circuit that receives one value of `H`, one half-divisor coefficient, or one orientation sign is rejected.

### B. Structured half-divisor recurrence

The C21 half-divisor contains one choice on a linear family of `tau`-pairs. Determine whether those choices are generated by an interval, automatic sequence, short recurrence, low displacement-rank object, or divide-and-conquer section law. Test generator covariance and held-out curves.

A recurrence in the hidden scalar index is rejected. The update must be applicable from public `Q` without knowing `k`.

### C. Transposed single-value evaluation

Search for a transposed functional that consumes only a compact oracle for the divisor or norm equation and returns the value at `y_Q`. Distinguish an implicit oracle from a dense degree-Theta(n) module. Charge oracle construction, query count, and state dimension.

### D. Resultant and residue circuits

Try exact first variations, residues, logarithmic derivatives, structured resultants, and norm-equation derivatives that reveal the canonical branch without factoring the full norm. Any branch-even quantity must be combined with an independently justified branch-odd anchor.

### E. Canonical infinity propagation

Use `R(infinity)=1` as a boundary condition. Determine whether it can be propagated to `Q` through a public logarithmic-depth jump law. Local nearest-neighbour propagation requiring a linear path is already closed. A valid law must jump by public powers or blocks without storing their full endpoint data.

### F. Scoped lower bound

If no construction survives, declare one broad implicit grammar, such as bounded-width arithmetic branching programs with public high-index leaves, black-box transposed divisor oracles, or divide-and-conquer section circuits. Prove a state, query, support, rank, or communication lower bound. Do not claim an unrestricted circuit lower bound.

### G. Formalization

Extend the Lean file from C21 with any exact abstract theorem proved in this package. Keep finite screens and unformalized geometric claims clearly separated.
