# Scientific validators

This directory contains only independently implemented validators for native
Research Engine runs.

Research Engine v0 currently has no implemented scientific validator. Candidate
`RE0-001` remains at intake until a validator recomputes the decisive Groebner
and elliptic-curve facts from raw artifacts. The small pure-Python validator in
`experiments/framework/fixtures/` is an infrastructure regression fixture, not
scientific evidence and not an executable research candidate.
