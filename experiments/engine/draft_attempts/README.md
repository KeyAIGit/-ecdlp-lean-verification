# Hypothesis draft attempts

This directory retains source-grounded attempts that did not become hypothesis
proposals. An accepted abstention is useful memory: it identifies the exact seed,
evidence packet, and missing object without inventing an executable candidate.

Draft attempts are untrusted model artifacts. They are not proposals, adversarial
proposal reviews, scientific outcomes, calibration labels, hypothesis-registry
entries, route decisions, or experiment authorizations. The deterministic engine
replays their fragment contract and provenance bindings and exposes the result to
future drafters so a later attempt must address the retained blockers rather than
silently repeat them.

Source and model-family independence must remain explicit. A post-hoc parser replay
against a commit-bound packet proves only schema and provenance consistency; it does
not attest which provider produced the text or that the cited claims support every
inference.
