# GLV diagonal-action obstruction

## Decision

The proposed coordinatewise substitution

```text
u_i = x_i^3
```

is not the quotient by the GLV symmetry relevant to a simultaneous point
relation. It is the invariant map for the larger coordinatewise group
`C3^m`. The curve automorphism acts diagonally, as one copy of `C3`.
On the dense locus where every coordinate is nonzero, the coordinatewise map
therefore merges `3^(m-1)` distinct diagonal orbits.

This closes `RE0-002-NONREDUNDANT-INVARIANT-QUOTIENT` as currently proposed
and blocks its dependent `m=3` scaling candidate. Reopening requires a
materially new mechanism beyond finite-orbit compression.

## Exact algebra

Let `k` have characteristic other than 3 and contain a primitive cube root
`beta`. Under the diagonal action

```text
(X_1, ..., X_m) -> (beta X_1, ..., beta X_m),
```

a monomial is invariant exactly when its total degree is divisible by 3. The
polynomial invariant ring is the third Veronese subring. It is generated by
all total-degree-three monomials, of which there are

```text
binomial(m + 2, 3).
```

For `m=2`, write

```text
a = X_1^3,  b = X_1^2 X_2,  c = X_1 X_2^2,  d = X_2^3.
```

The affine presentation has the toric relations

```text
b^2 = a c,  b c = a d,  c^2 = b d.
```

By contrast, `k[X_1^3, ..., X_m^3]` is the invariant ring of `C3^m`.
Generically its quotient fiber has size `3^m`, while a free diagonal orbit has
size 3.

This generator count does not prove that every rational or localized
formulation must use more variables: on a dense chart, ratios can give a
smaller rational coordinate system. It does prove that the specific
coordinatewise polynomial quotient loses relative phase and cannot be treated
as the exact diagonal quotient.

## Frozen finite witness

`artifact.json` exhaustively enumerates the x-coordinates on

```text
E: y^2 = x^3 + 11 over F_1009
```

with the nontrivial cube root `beta=374`. The curve has 967 points and 483
on-curve x-coordinates. Zero is not one of them, so the action is free in this
witness.

For ordered x-coordinate pairs:

| Set | Exact count |
|---|---:|
| Graph of the diagonal action `x_2 = beta x_1` | 483 |
| Coordinatewise equality `x_1^3 = x_2^3` | 1449 |
| Pairs admitted only after relative phase was forgotten | 966 |

The coordinatewise condition is exactly three times larger; two thirds of its
pairs are not on the selected diagonal-action graph.

Run:

```bash
python3 experiments/glv_diagonal_obstruction/generate.py --check
python3 experiments/glv_diagonal_obstruction/validate.py
```

The producer and validator do not import one another. The validator checks the
committed SHA-256, independently enumerates every field element and y-value,
reconstructs every raw set, and verifies the exponent identities for the
toric relations.

## Claim boundary

This witness is deliberately narrower than the wording in the external
review:

- It is an exact counterexample to recovering diagonal phase from
  coordinatewise cubes.
- A finite group of order 3 can provide only a fixed orbit-cardinality
  reduction by itself.
- It is not a Semaev attack experiment and does not show that every solution
  of a particular Semaev `u`-system is false.
- For a fixed nonzero target, scaling only the factor variables generally
  changes the target to its GLV image. Any future quotient must specify this
  target-fiber behavior explicitly.
- It is not a universal lower bound on Groebner complexity. A future proposal
  may reopen the route only by supplying a different, exact algebraic
  mechanism with a growth-relevant prediction, not by relabeling the same
  finite orbit compression.
- It says nothing about a practical attack on secp256k1.
